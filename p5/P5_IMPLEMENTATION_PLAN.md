## 1. 成功阶梯：什么算"复现了"

论文的完整复现需要 KUKA LWR / IIWA 两台真机、RViz 平台、作者未发布的训练集，以及被移除的 CVXGEN
求解器。这些**永远不在 P5 的范围内**。因此必须先定义"通过"的天花板，否则实现阶段一定会出现
"整体看起来对 → 宣称复现成功"的滑坡。

### 1.1 三级阶梯

| 级别 | 名称 | 判据 | P5 是否追求 |
|---|---|---|---|
| L1 | `MECHANISM_VERIFIED` | 每个数学构件有 ≥2 条**互相独立**的验证路径（解析 vs 数值、两种求解器、有限差分 vs 解析梯度），且负测试全部按预期失败 | ✅ 必须达到 |
| L2 | `ALGORITHM_NUMERICAL_VERIFIED (D082)` | L1 全部通过 + **T10 端到端数值实验通过**（无机器人、无渲染）：异步→同步切换可观测、SCA 开关的匹配对照成立 | ✅ **主验收目标（T10 强制）** |
| L3 | `FULL_PAPER_REPRODUCED` | 复现论文表格/图的具体数值 + 硬件实验 | ❌ **明确放弃** |

**D082 范围**（沿用 P3 的命名）：只做**算法层数值**，不做平台层、不做硬件层、不复现论文的
成功率/失败率统计（那些数字依赖真机与操作者）。

**验收口径（评审 Q1/Q5）**：T01–T08 与 **T10** 全部为 `MINIMUM_ESSENTIAL`；T09 **本轮未授权**。
只有全部强制任务达到各自的验收条件，才授予 `ALGORITHM_NUMERICAL_VERIFIED (D082 scope)`；
任一强制任务失败，只报告相应部分完成状态（`PARTIAL_*`），不得降格授予。

## 2. 范围裁决

### 2.1 为什么 A、B、C 三组都是 `MINIMUM_ESSENTIAL`

立项卡片 `references/P5_qp_coordination.md` 把"学习 SCA"降级为"核心 QP 稳定之后的 paper-like 扩展"。
**这个排序在科学上不成立**，理由已在 `P5_PAPER_STUDY.md` §1.3 给出，这里给出可执行的结论：

| 组件 | 若省略会怎样 | 裁决 |
|---|---|---|
| **A** 同步/异步 DS + τ 分配 | 只剩一个普通多臂 DS，"unified framework"这个卖点整体消失；QP 的输入 `ξ̇^R` 也失去来源 | 必需 |
| **B** 集中式 QP IK | 论文第 3 节主体，且是 A 与 C 的唯一汇合点 | 必需 |

即：`MINIMUM_ESSENTIAL` = {T01…T08}，`OPTIONAL_EXTENSION` = {T09, T10}。

### 2.2 官方代码在计划中的角色

官方代码**不是**实现基础，而是**三样东西**：

1. **对照物**：T01/T03 用它量化"论文式 vs 作者实现"的偏差（`DEVIATION_REFERENCE`）。
2. **黄金数据源**：T06/T07 直接用随仓库发布的 `.mat` 模型（`2d_example.mat`、36D 稀疏模型），因为
   重训不可行（O5），而评估可行。

### P5-T01 · 同步分配 τ 动力学与其边界行为

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL` + `DEVIATION_REFERENCE` ｜ **风险**：LOW

**源方程**
```
(8)   τ̇_ci = τ_ci (1 − τ_ci) · G(ξ^O, ξ̇^O) / k ,      τ_ci(0) = ε
      G(ξ^O, ξ̇^O) = − ξ̇^Oᵀ (ξ^O − ξ^O(T*)) / ( ε + ‖ξ^O − ξ^O(T*)‖² )
(6)   τ_ci = 0  ⇒  ẋ_i^R 退化为纯异步 DS（跟随 x_i^d）
(7)   τ_ci = 1  ⇒  ẋ_i^R 退化为纯同步 DS（跟随 x_i^V）
```
`k > 0` 在**分母**（`k` 越大切换越慢）；`G > 0` ⟺ 物体正在朝拦截点靠近（`ξ̇^Oᵀ(ξ^O−ξ^O(T*)) < 0`）。

**官方代码可用性**
`Multiarm_ds::calculate_coordination_allocation()`（HEAD `c6ccbf48`，LGPL-3.0）。判读 `CODE_DIVERGENT`，
五处差异：(a) 只用 `ξ̇^O` 的 **x 分量**而非完整内积；(b) 分母是到**当前虚拟物体**的距离，不是到拦截点
的距离 `+ε`；(c) 无负号（符号由 `ξ^O−ξ^V` 的方向承担）；(d) `1/k` 折成常数 `10`；(e) 加了论文没有的硬
饱和 `τ∈[0.001,0.99]`。→ 只作 `DEVIATION_REFERENCE`。

**独立数学验证**
1. **闭式解**：固定 `ξ^O, ξ̇^O`（`G` 为常数）时，(8) 是 logistic 方程，有精确解
   `τ(t) = 1 / (1 + ((1−τ₀)/τ₀)·exp(−G t / k))`。用它检验 RK4 的步长收敛阶（步长减半，误差应 ×1/16）。
2. **极限一致性**：把 τ 强行置 0/1，检查 (2) 的右端分别退化为 `ẋ^d` 与 `ẋ^V` 的纯跟踪式（即 (6)(7)）。
3. **不变量**：`τ ∈ (0,1)` 恒成立（logistic 结构保证），任何越界都是实现 bug 而非数值噪声。

**正测试**
- P1.1 `G > 0`：τ 单调升，`t→∞` 趋 1，与闭式解相对误差 < 1e-6。
- P1.2 `G < 0`：τ 单调降，趋 0。
- P1.3 `G = 0`：τ 恒定等于 `τ₀`（导数恒为 0）。
- P1.4 步长序列 `dt ∈ {1e-2, 5e-3, 2.5e-3}` 的收敛阶 ∈ [3.7, 4.3]（RK4）。
- P1.5 与官方变体（`DEVIATION_REFERENCE`）在同一 `ξ^O(t)` 上的 τ(t) 曲线并置，记录 RMS 偏差数值。
- P1.6 **端点平衡性（评审更正）**：`τ₀ = 0` 与 `τ₀ = 1` 是 logistic 向量场的**两个唯一平衡点**
  （`f(0)=f(1)=0` 且端点处 `f'≠0` 的符号分析可判）。对有限 `k`、有限 `G`，解恒等于端点值：

- P4.1 行满秩、无约束、`W=I`：`q̇` 与伪逆解一致（< 1e-12）；`‖Jq̇ − ξ̇‖ < 1e-9`。
- P4.2 `W ≠ I`（对角加权）：`q̇ᵀWq̇` 不大于随机采样的 1e3 个可行点（最优性）。
- P4.3 2-DOF 臂跟踪直线：末端误差单调下降至 < 1e-6。
- P4.4 限位激活：`q` 逼近 `q⁺` 时 `q̇` 被 `μ(q⁺−q)` 限住，`q(t)` **不越界**。
- P4.5 三路求解器解差 < 1e-6（一致情形）/ < 1e-4（含激活不等式）。
- P4.6 秩亏但一致（`J` 有两行相同、`ξ̇` 两分量相等）：必须返回 `RANK_DEFICIENT_CONSISTENT` 且
  `‖Jq̇ − ξ̇‖ < 1e-9`，解为最小范数。
- P4.7 求解时间：单次 < 1 ms（`4` 自由度），记录 1e4 次的 p50/p99。

**负测试**
- N4.1 **秩亏且不一致**（`J` 两行相同、`ξ̇` 两分量不等）：必须报 `EQUALITY_INFEASIBLE`，
  **且不得返回任何 `q̇`**。若实现返回 `pinv` 解，其残差必然 > 0，测试直接显示"返回了不可行解"。
- N4.2 盒约束互斥（`θ̇⁻ > θ̇⁺`）：报 `BOUND_INFEASIBLE`，不返回上一步的 `q̇`。
- N4.3 `W` 奇异或 `λ_min(W) ≤ 0`：报 `ILL_CONDITIONED`，不"碰巧解出来"。
- N4.4 `ξ̇` 维数与 `J` 行数不符：维度断言。
- N4.5 把 `μ` 设成 `0`：`θ̇± = q̇±`，限位失效（`q` 可能越界）—— 确认 `μ` 真的在起作用。

### P5-T05 · LVI 投影动力学求解器与定理 3 被动性

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL` ｜ **风险**：MEDIUM

**源方程**
```
(19)  P_Ω( u − (M u + b) ) − u = 0                       （LVI / 不动点形式）
(20)  u̇ = ( I + Mᵀ ) ( P_Ω( u − (M u + b) ) − u )        ← 括号位置是 (I+Mᵀ)(P(·)−u)
(21a) M = [ W    −Jᵀ   −∇Γ ;
            J     0     0   ;
            ∇Γᵀ   0     0   ]
(21b) b = [ 0 ;  −ξ̇^R ;  log(Γ−1) ]                      ← 见下方方框，论文印 −log(Γ−1)
(22)  P_Ω 逐元素饱和（三分支）
(23)  u⁻ = [θ̇⁻; −∞; 0] ,  u⁺ = [θ̇⁺; +∞; +∞]
```

> **方框：为什么 (21b) 第三项必须是 `+log(Γ−1)`**
>
> 取 (17d) 的等价形式 `h(q̇) = −∇Γᵀq̇ − log(Γ−1) ≤ 0`，乘子 `ν ≥ 0`（与 (23) 的 `ν ≥ 0` 一致）。
> LCP 的互补行是 `∇Γᵀq̇ + b₃ = 0`（对偶自由时），而约束激活时 `∇Γᵀq̇ = −log(Γ−1)`，故
> `b₃ = −∇Γᵀq̇ = +log(Γ−1)`。
> 论文印的是 `−log(Γ−1)`，与本式相反，也与它自己的 (17d) 相反。官方代码写 `lambda*log(Γ_−1)`：
> **方向对、`lambda` 未初始化**（`qp_ik_solver.h` 第 161 行附近）。
> 默认策略见 §2.3/O3。

**官方代码可用性**
`QP_IK_solver::Solve()` 的 Dynamical 分支判读 `CODE_MATCH`（含 `(I+Mᵀ)(P(·)−u)` 的括号位置），
(full-width blocks) 与 (21a)(22)(23) 逐元素对应。缺陷：`Omega_projector()` **计算了 `output` 却
`return Input;`**（`CODE_BUGGY`，主循环用内联版本故未暴露）；`Gamma_=2`、`DGamma_=0` 且从不更新
（SCA 路径是死代码）。

**独立数学验证**
1. **不动点残差**：`‖P_Ω(u − Mu − b) − u‖ < 1e-8`（KKT 的等价刻画）。
2. **与 QP 解一致**：同一 `(M,b,Ω)` 用 SLSQP 直接解 (17)，比较 `q̇` 分量（< 1e-6），并比较完整 KKT 残差
   （原始残差 + 对偶残差 + 互补松弛）。
3. **与解析 KKT 一致**：仅等式时退化为 `W⁻¹Jᵀ(JW⁻¹Jᵀ)⁻¹ξ̇`（< 1e-9）。
4. **定理 3 的被动性不等式（评审更正，不是 `V̇ ≤ 0`）**：
   论文定理 3 的准确内容是：以 `Y = u` 为输出、`U = (I+Mᵀ)P_Ω(u − (Mu+b))` 为输入，系统 (20) 被动，
   即存在 `ψ(u) ≥ 0` 使 `V̇ + ψ ≤ YᵀU`。论文 App. F 给出的是**等式**：
   ```
   V = ½uᵀu ,  V̇ = uᵀ(I+Mᵀ)(P_Ω(u−Mu−b) − u)
   ⇒  V̇ + uᵀ(I+Mᵀ)u = uᵀ(I+Mᵀ)P_Ω(u−Mu−b) = YᵀU
     ψ(u) = uᵀ(I+Mᵀ)u = ‖u‖² + uᵀMu
   ```
   因此本任务检验的是：
   - **恒等式** `|V̇ + ψ − YᵀU| < 1e-10`（这是对 `u̇` 实现的直接检验，解析上应精确成立）；
   - **耗散非负** `ψ ≥ 0`（`sym(I+M) ⪰ 0`，在 `W ⪰ 0` 下成立）；
   - **`V̇` 允许为正**：`V̇ = YᵀU − ψ`，输入供能时当然可以为正。**不得**把 `V̇ ≤ 0` 当作通过/失败判据。

**正测试**
- P5.1 凸 QP（含激活不等式）收敛到与 SLSQP 相同的 KKT 点（解差 < 1e-6，乘子差 < 1e-5）。
- P5.2 `ν ≥ 0` 全程成立（违反次数 = 0）；`‖P_Ω(u−Mu−b) − u‖ < 1e-8`。
- P5.3 迭代次数 < 1e4 且残差单调降到 1e-9。
- P5.4 冗余/重复约束（同一行写两次）：仍收敛（`M` 奇异但 LVI 允许）。
- P5.5 `(I+Mᵀ)` 的转置位置：把 `Mᵀ` 写成 `M`，无约束情形下轨迹不同（"括号/转置敏感"的正向确认）。
- P5.6 被动性恒等式 `|V̇ + ψ − YᵀU| < 1e-10` 沿轨迹逐点成立；`ψ_min ≥ -1e-12`。
- P5.7 记录 `V̇` 的**符号分布**：允许出现正值区间，并在报告里说明它对应输入供能。

**负测试**
- N5.1 `W` 病态（条件数 1e12）：必须检出（残差不降）并报 `ILL_CONDITIONED`，**不得**继续迭代到超时。
- N5.2 **`λ = 0` 的可行锥（评审更正）**：`λ=0` 时 `b₃ = 0`，约束退化为 `∇Γᵀq̇ ≥ 0`，即**只禁止减小 Γ**，
  允许沿等值面滑动、也允许朝自由空间运动。断言必须检查
  `{q̇ : ∇Γᵀq̇ ≥ 0}` 这个半空间（含沿等值面的方向），**不得**断言"梯度方向速度恒为 0"。
  同时记录：`λ=0` 时没有裕度，离散误差可以让 Γ 漂到并穿过边界（这正是它不如 `λ=1` 的原因）。
- N5.3 `Omega_projector()` 的 `return Input` 缺陷：单元测试喂越界 `u`，投影必须裁剪；按官方语义写会失败
  —— 把上游缺陷钉成可复现的失败用例。
- N5.4 `b₃` 取 `−log(Γ−1)`：约束把 `q̇` 推向 `−∇Γ` 方向（朝碰撞），与 (17d) 相反 ⇒ 必须红。
- N5.5 `Ω` 上下界次序颠倒（`u⁻ > u⁺`）：维度/次序断言。
- N5.6 故意漏掉 `(I+Mᵀ)` 中的 `I`：被动性恒等式残差必须变为 `O(1)`，测试红。

**计算需求**：`u` 维数 `d_Q + d_n + d_c ≈ 10–25`；每次求解 1e2–1e3 次矩阵-向量乘，< 5 ms；1e3 次求解 ≈ 5 s。

**预期图与指标**
- 图 `t05_residual_iter.png`：残差 vs 迭代（对数），含病态 `W` 的失败曲线。
- 图 `t05_passivity.png`：`ψ(u)`、`YᵀU`、`V̇` 三条曲线 + 恒等式残差（对数），标出 `V̇ > 0` 的供能区间。
- 图 `t05_vs_slsqp.png`：`q̇` 逐元素对照 + 乘子对照。
- 指标：`kkt_residual_primal/dual`、`iterations`、`nu_min`、`passivity_identity_residual`、`psi_min`、
  `Vdot_positive_fraction`、`solver_gap`。

**科学保真度与局限**
- 保真：`ORIGINAL` —— 这是全库保真度最高的两条之一（与 (2) 并列），矩阵结构与括号位置都与论文一致。
- 局限：**不宣称**定理 3 的证明被复现；只做恒等式与耗散项的数值验证（恒等式可精确检验，但"被动"作为
  系统性质仍需沿轨迹逐点检查，单条轨迹不构成证明）。
- 局限：(22) 的逐元素投影要求 `Ω` 是盒；若将来引入耦合约束，LVI 形式不再直接适用，必须重新推导。

### P5-T08 · SCA 约束进入 QP 的安全闭环（低维）

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL`（约束结构）+ `ADAPTATION`（低维替代模型） ｜ **风险**：HIGH

**源方程**
```
(17d)  − ∇Γ^{ij}(q^{ij})ᵀ q̇^{ij} ≤ log( Γ^{ij}(q^{ij}) − 1 )     ∀(i,j)
(26)   ∇_q Γ = (∂Γ/∂f)(∂f/∂q)        ← 零填充嵌入到 d_Q 维
(16)   Γ>1 自由 / =1 边界 / <1 碰撞
(21a)(21b)  SCA 进入 M、b 的第三行/块（符号见 T05 方框）
```
(17d) 的语义（论文原文 p.1215）：远离边界时 `log(Γ−1)` 为正 ⇒ 放松约束；接近边界时为负 ⇒ 把关节推离
边界；`Γ<1`（已在边界内）时 `log(Γ−1)` **无定义**，论文给出的处置是：

> "we replace `log(Γ−1)` with a large negative number that pushes the robots outward towards the boundary."

这条**是论文明确写下的回退**，必须作为 `PAPER_FALLBACK` 单独实现与标注，**不得**与字面 log 形式混为一谈，
也不得用"静默限幅"冒充它。

**官方代码可用性**
`QP_IK_solver` 的 `M`/`b` 结构存在，但 `Gamma_ = 2`（常数）、`DGamma_ = 0`（零向量）且**从不更新**，
`get_gamma()` 只声明未定义 ⇒ **官方 QP 实际没有 SCA**（O9）。本任务的约束链路必须自建。

**低维替代模型的构造（关键设计）**
用 `T06` 的官方 2D CPSP 模型作为**学到的约束"神谕"**：
- 特征 `f = p_2(q) − p_1(q) ∈ R²`（两个体点的相对位置），与 2D 模型的训练特征同维；
- (26) 成为可精确书写的链式法则：`∇_qΓ = (J_2(q) − J_1(q))ᵀ ∇_f Γ`，`J_k = ∂p_k/∂q`（`2×d_Q`）；
- `(17d)` 的 `∇Γ^{ij}` 通过零填充嵌入 `d_Q`（只有 `q^{ij}` 对应的列非零）；
- 标定沿用 T07 冻结的 `Γ_cal = 1 + Γ_raw/κ`，`κ=1`，故 `Γ_cal ≥ 1 ⟺ Γ_raw ≥ 0`。**报告里写明用的是哪一个**。

好处：**真的用了学到的模型**（不是手写距离函数），且 (26) 可从头验证。
代价：2D 模型的绝对尺度与平面双臂几何只有**解释性**对应，属 `ADAPTATION`。

**四类事件必须分开计数（评审要求）**

| 类别 | 含义 | 处置 |
|---|---|---|
| `LOG_DOMAIN` | `Γ_raw ≤ 0`，字面 `log` 不可用 | 触发 `PAPER_FALLBACK`（大负数），单独计数 |
| `QP_INFEASIBLE` | 约束集空（含 `θ̇⁻>θ̇⁺`、`Γ` 已越界且回退仍不可行） | 报不可行，本步不做任何运动，计数 |
| `SOLVER_FAILURE` | LVI/SLSQP 未收敛（残差 > tol 或迭代超限） | 报失败，按"保持上一步"或"停止"，计数 |
| `BOUNDARY_CROSSING` | 轨迹上出现 `Γ_raw < 0` 的**实际穿越** | 安全判据的核心事件，计数 |

**独立数学验证**
1. **链式法则**：`∇_qΓ` 与"对 `Γ(f(q))` 整体做中心差分"比较（`d_Q=4`），相对误差 < 1e-6。
2. **符号判定（不依赖 FD）**：沿 `+∇_qΓ` 走一小步 `Γ` 必须增大，沿 `−∇_qΓ` 必须减小。
3. **约束激活的 KKT**：构造使约束恰好激活的构型，检查 `∇Γᵀq̇ = −log(Γ−1)` 且 `ν > 0`（`λ=1`）。
4. **积分步长收敛**：`dt ∈ {2e-3, 1e-3, 5e-4}` 下 `min Γ_raw` 与穿越计数必须收敛（差异 < 容差）。
5. **中间轨迹检查**：不只看终点，逐步记录 `Γ_raw(t)`、激活标志、`ν`、QP 残差。

**正测试**
- P8.1 开启 SCA（`λ=1`，字面 log 形式），双臂相向直线运动：`min_t Γ_raw(t) ≥ -1e-6`，穿越计数 = 0。
- P8.2 约束激活率 > 0（否则约束没起作用，测试无意义）。
- P8.3 `∇_qΓ` vs FD 相对误差 < 1e-6；沿 `+∇Γ` 的 `Γ` 单调增。
- P8.4 四类事件计数表完整：`LOG_DOMAIN + QP_INFEASIBLE + SOLVER_FAILURE + BOUNDARY_CROSSING` 逐项报告，
  且每类都有触发/未触发的证据（计数为 0 也要有"为什么不触发"的说明）。
- P8.5 关闭 SCA 的对照：`min_t Γ_raw(t) < 0`，穿越计数 > 0。

**负测试**
- N8.1 **翻转 `∇Γ` 符号**：必须加速穿越（穿越更早、更频繁），证明符号敏感性。
- N8.2 `λ=0`：约束只禁止减小 `Γ`，没有裕度；离散误差下应出现穿越（或贴着边界滑动），
  与 `λ=1` 形成对照。**不得**写成"系统卡死"。
- N8.3 `(21b)` 用 `−log(Γ−1)`：构型被吸向边界 → 穿越计数显著上升，必须红。
- N8.4 去掉零填充（维度或列位置写错）：维度断言拦截。
- N8.5 **静默限幅检查**：代码里若出现"把 `log` 结果 clip 到某上下界"的路径，必须带显式标记；测试通过
  扫描实现路径确认**没有**无标记的 clamp（用猴子补丁替换 `np.clip` 触发即失败）。
- N8.6 步长放大 10×：穿越计数应恶化或至少变化，证明离散化误差真实存在（不许"任何步长都完美"）。

**计算需求**：`d_Q = 4`（2 臂 × 2 关节），`d_n = 2`，`d_c = 1`；每次 QP `10–20` 维，
LVI 收敛 1e2–1e3 迭代；`2000` 步闭环 ≈ `5–20 s`，三组步长共 ≈ 60 s。

### P5-T10 · 端到端数值实验（L2 验收强制项，无机器人、无渲染）

- **优先级**：`MINIMUM_ESSENTIAL`（评审 Q1/Q5 明确改为强制）｜ **标签**：`ADAPTATION` ｜ **风险**：MEDIUM

**源方程**：`(2) + (8) + (9) + (17) + (20) + (17d)` 的串联。
**官方代码可用性**：`Multiarm_ds` + `QP_IK_solver` 的可读部分仅作行为参照，不作实现基础。

**被串联的四个子系统（必须逐个可追溯到已验收任务）**

```
τ 动力学 (8)  →  LPV 跟踪 DS (2)  →  虚拟物体 (9)/(36)  →  集中式 QP (17)  →  LVI (20)
   T01              T02                  T03                 T04/T08          T05
```

**控制与存储量的正确定义（评审更正）**

`Σ ½‖q̇‖²` **不是**物理能量，也不是普适的被动性度量（关节速度的平方和没有对应的供给率）。
本任务改为在有明确假设的前提下报告以下量：

| 量 | 定义 | 假设 / 说明 |
|---|---|---|
| 控制输入功率 | `P_in = ξ̇^{Rᵀ} f`，`f` 为任务空间广义力（由 QP 的第一行 `Wq̇` 与 `Jᵀν` 反解得到） | 把 QP 视为速度级控制器，`f = Wq̇`（`W` 近似惯量）——**这是假设，必须写在报告里** |
| 存储函数 | `S = ½ξ̃ᵀξ̃`，`ξ̃ = JJ⁺ξ̇^R − ẋ^R` 之类的跟踪误差范数 | 只作为**跟踪误差**度量，不称为能量 |
| 耗散 | `ψ = uᵀ(I+Mᵀ)u`（定理 3 的 `ψ`） | 与 T05 同一口径 |
| 数值能量账 | `∫P_in dt` 与 `ΔS + ∫ψ dt` 的偏差 | 只作**实现自洽性**检查，偏差大即说明实现有不守恒项 |

> 报告里禁止出现"系统能量单调下降"这类断言；只能写"在给定假设下，`∫P_in − ΔS − ∫ψ` 的残差为 X"。

**独立数学验证**
1. **与子任务一致**：T01–T08 的对应指标（`τ` 曲线、`Γ_raw` 最小值、KKT 残差）在端到端里复现到容差内。
2. **行为切换的可观测判据**（必须事先定义，不许事后挑选）：以 `τ(t)` 与末端相对距离的**交叉点**为切换
   时点 —— 具体地，`t_switch := first t where τ ≥ 0.5`，并同时报告"臂间相对距离开始下降"的时刻，两者
   应同向。
3. **数值能量账**：按上表计算残差并报告；不解释成物理结论。

**正测试**
- P10.1 同一 DS 下异步→同步切换可观测：`τ` 从 `ε` 单调升到 >0.9，且 `t_switch` 落在预设窗口内。
- P10.2 SCA 开启时全程无 `BOUNDARY_CROSSING`（与 T08 的判据同口径）。
- P10.3 SCA 关闭的**匹配对照**（同初值、同目标、同 `dt`、同种子）出现 `BOUNDARY_CROSSING`。
- P10.4 端到端复现子任务指标：`max|Γ_raw^{e2e}(t) − Γ_raw^{T08}(t)|` 在容差内；KKT 残差同量级。

**负测试**
- N10.1 去掉 SCA：必须出现穿越（同 P10.3，作为负对照的独立断言）。
- N10.2 去掉 `τ` 分配（`τ ≡ 1` 或 `τ ≡ 0`）：不得出现切换（这是"简化即失效"的证据）。
- N10.3 **任一子任务未通过时，禁止用端到端结果掩盖**：`run_all.py` 里 T10 的状态由 T01–T08 的
  `AND` 门控；只要有一个子任务 FAIL，T10 最高只能是 `BLOCKED_BY_UPSTREAM`。
- N10.4 把 `λ` 从 1 改成 0：穿越计数应上升（与 T08 的 N8.2 同向）。
- N10.5 `dt` 加倍：切换时点与 `min Γ_raw` 必须变化（否则说明积分步长没生效）。
