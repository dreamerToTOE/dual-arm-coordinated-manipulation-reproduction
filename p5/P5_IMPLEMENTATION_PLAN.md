## 1. 成功阶梯：什么算"复现了"

论文的完整复现需要 KUKA LWR / IIWA 两台真机、RViz 平台、作者未发布的训练集，以及被移除的 CVXGEN
求解器。这些**永远不在 P5 的范围内**。因此必须先定义"通过"的天花板，否则实现阶段一定会出现
"整体看起来对 → 宣称复现成功"的滑坡。

### 1.1 三级阶梯

| 级别 | 名称 | 判据 | P5 是否追求 |
|---|---|---|---|
| L1 | `MECHANISM_VERIFIED` | 每个数学构件有 ≥2 条**互相独立**的验证路径（解析 vs 数值、两种求解器、有限差分 vs 解析梯度），且负测试全部按预期失败 | ✅ 必须达到 |
| L2 | `ALGORITHM_NUMERICAL_VERIFIED (D082)` | L1 全部通过 + 端到端数值闭环（无机器人、无渲染）行为定性正确（同步/异步切换、Γ≥1 保持） | ✅ 目标（= T10） |
| L3 | `FULL_PAPER_REPRODUCED` | 复现论文表格/图的具体数值 + 硬件实验 | ❌ **明确放弃** |

**D082 范围**（沿用 P3 的命名）：只做**算法层数值**，不做平台层、不做硬件层、不复现论文的
成功率/失败率统计（那些数字依赖真机与操作者）。

## 2. 范围裁决

### 2.1 为什么 A、B、C 三组都是 `MINIMUM_ESSENTIAL`

立项卡片 `references/P5_qp_coordination.md` 把"学习 SCA"降级为"核心 QP 稳定之后的 paper-like 扩展"。
**这个排序在科学上不成立**，理由已在 `P5_PAPER_STUDY.md` §1.3 给出，这里给出可执行的结论：

| 组件 | 若省略会怎样 | 裁决 |
|---|---|---|
| **A** 同步/异步 DS + τ 分配 | 只剩一个普通多臂 DS，"unified framework"这个卖点整体消失；QP 的输入 `ξ̇^R` 也失去来源 | 必需 |
| **B** 集中式 QP IK | 论文第 3 节主体，且是 A 与 C 的唯一汇合点 | 必需 |
| **C** 学习 SCA 边界 | 论文 8 页篇幅（Γ、∇Γ、CPSP、2 ms 预算）都在这里；**且官方代码里这条链路是死代码（O9）**，不复现就无从判断论文主张是否成立 | 必需 |

即：`MINIMUM_ESSENTIAL` = {T01…T08}，`OPTIONAL_EXTENSION` = {T09, T10}。

### 2.2 官方代码在计划中的角色

官方代码**不是**实现基础，而是**三样东西**：

1. **对照物**：T01/T03 用它量化"论文式 vs 作者实现"的偏差（`DEVIATION_REFERENCE`）。
2. **黄金数据源**：T06/T07 直接用随仓库发布的 `.mat` 模型（`2d_example.mat`、36D 稀疏模型），因为
   重训不可行（O5），而评估可行。
3. **缺陷证据**：`QP_IK_solver` 的 CVXGEN 缺失、`Omega_projector` 的 `return Input`、`Gamma_` 恒为 2
   —— 这些是 `P5_OFFICIAL_CODE_AUDIT.md` 的结论，也是本项目必须 clean-room 重写的**法律与工程双重理由**。

**任何 P5 代码不得是官方代码的翻译。** 只允许携带：数值常数（`mu=20`、`eta=0.9`、`k_max=3000`、
`-g 3.3`）、文件格式事实、以及"某函数行为与论文不一致"这一观察。

### P5-T01 · 同步分配 τ 动力学与其边界行为

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL` + `DEVIATION_REFERENCE` ｜ **风险**：LOW

**源方程**
```
(8)   τ̇_ci = τ_ci (1 − τ_ci) · G(ξ^O, ξ̇^O) / k ,      τ_ci(0) = ε
      G(ξ^O, ξ̇^O) = − ξ̇^Oᵀ (ξ^O − ξ^O(T*)) / ( ε + ‖ξ^O − ξ^O(T*)‖² )
(6)   τ_ci = 0  ⇒  ẋ_i^R 退化为纯异步 DS（跟随 x_i^d）
(7)   τ_ci = 1  ⇒  ẋ_i^R 退化为纯同步 DS（跟随 x_i^V）
```
`k > 0` 在**分母**（`k` 越大切换越慢）；`G > 0` ⟺ 物体正在朝拦截点靠近（`ξ̇^Oᵀ(ξ^O−ξ^O(T*)) < 0`）。

**官方代码可用性**
`Multiarm_ds::calculate_coordination_allocation()`（HEAD `c6ccbf48`，LGPL-3.0）。判读 `CODE_DIVERGENT`，
五处差异：(a) 只用 `ξ̇^O` 的 **x 分量**而非完整内积；(b) 分母是到**当前虚拟物体**的距离，不是到拦截点
的距离 `+ε`；(c) 无负号（符号由 `ξ^O−ξ^V` 的方向承担）；(d) `1/k` 折成常数 `10`；(e) 加了论文没有的硬
饱和 `τ∈[0.001,0.99]`。→ 只作 `DEVIATION_REFERENCE`。

**独立数学验证**
1. **闭式解**：固定 `ξ^O, ξ̇^O`（`G` 为常数）时，(8) 是 logistic 方程，有精确解
   `τ(t) = 1 / (1 + ((1−τ₀)/τ₀)·exp(−G t / k))`。用它检验 RK4 的步长收敛阶（步长减半，误差应 ×1/16）。
2. **极限一致性**：把 τ 强行置 0/1，检查 (2) 的右端分别退化为 `ẋ^d` 与 `ẋ^V` 的纯跟踪式（即 (6)(7)）。
3. **不变量**：`τ ∈ (0,1)` 恒成立（logistic 结构保证），任何越界都是实现 bug 而非数值噪声。

**正测试**
- P1.1 `G > 0`：τ 单调升，`t→∞` 趋 1，与闭式解相对误差 < 1e-6。
- P1.2 `G < 0`：τ 单调降，趋 0。
- P1.3 `G = 0`：τ 恒定等于 `τ₀`（导数恒为 0）。
- P1.4 步长序列 `dt ∈ {1e-2, 5e-3, 2.5e-3}` 的收敛阶 ≈ 4（RK4）。
- P1.5 与官方变体（`DEVIATION_REFERENCE`）在同一 `ξ^O(t)` 上的 τ(t) 曲线并置，记录 RMS 偏差数值。

**负测试**
- N1.1 `τ₀ = 0` 或 `τ₀ = 1`：必须检出为退化输入并给出告警（logistic 解在端点不唯一）。
- N1.2 `k → 0⁺`：`τ̇` 爆炸，必须触发步长自适应或拒绝，**不得**静默产生 `inf/nan`。
- N1.3 `‖ξ̇^O‖` 极大（>1e3）：固定步长下必须被检出（越界或能量不守恒），不能悄悄通过。
- N1.4 人为把 `k` 放到分子：τ 曲线形状反向（慢→快），断言必须失败 —— 用于确认测试真的在测 `k` 的位置。

**计算需求**：纯 CPU 单核；ODE 积分 1e5 步 × 单标量状态，< 1 s；无外部数据；零新依赖（`numpy`）。

**预期图与指标**
- 图 `t01_tau_three_cases.png`：`G>0 / G<0 / G=0` 三条 τ(t) 叠加闭式解虚线。
- 图 `t01_tau_vs_G.png`：τ–G 相图（`G` 由 −5 到 +5 扫描，固定 t=1）。
- 图 `t01_deviation.png`：论文式 vs 官方变体的 Δτ(t)。
- 指标：`rel_err_closed_form`、`convergence_order`、`tau_violations`、`rms_dev_official`。

**科学保真度与局限**
- 保真：式 (8) 的每一个符号位置都可由论文正文与 `k` 的语义唯一确定，属于真正 `ORIGINAL`。
- 局限：**不宣称**复现论文 Fig.3 的 τ 曲线形状——那需要作者真实场景的 `ξ^O(t)`，未发布。

### P5-T02 · LPV/GMR 调度参数与定理 1 的数值校核

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL` ｜ **风险**：MEDIUM

**源方程**
```

### P5-T03 · 虚拟物体动力学：式 (11) 的自消性质与官方实现差异

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL`（推导）+ `DEVIATION_REFERENCE` ｜ **风险**：MEDIUM

**源方程**
```
(9)   ẋ^V = [ γ ẋ^O + γ̇ x^O + A^V x^V − γ x^O + Σ_i τ_ci U_i ] / (1 + Σ_i τ_ci)
(10)  U_i = ẋ_i^R − A_i(θ_i)( x_i^R − x_i^d − τ_ci (x_i^V − x_i^d) ) − τ̇_ci (x_i^V − x_i^d)

(36)  （附录 D 中的同型式，不含 τ̇）

```

**这一步到底抵消了什么（必须先讲清，否则测试会写错）**

把 (2) 代入 (10)：

```
U_i = [τ̇(x^V−x^d) + τ ẋ^V + A_i(·)] − A_i(·) − τ̇(x^V−x^d) = τ_ci ẋ_i^V
```

代回 (9) 得到 (11)。**关键结论不是"τ 消失了"，而是"τ̇ 消失了"**：`τ̇` 在 (10) 里被显式减掉、

- (11) **不含 `τ̇`**，即同步分配的变化率 `G/k` **不直接驱动**虚拟物体；
- `τ` 仅通过权重 `(1+Στ)` 与 `Σ τ_i ẋ_i^V` 进入 —— 这是**有影响但间接**的影响。

审计中 `P5_EQUATION_AUDIT.md` §6.1 的表述是"与 τ 无关 / 退化为 (36)"，**本计划收紧为"与 τ̇ 无关"**，
因为这才是在代数上可验证的命题。若评审认为原文表述更强，请以本节的推导为准并批准更正。

### P5-T05 · LVI 投影动力学求解器与定理 3 被动性

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL` ｜ **风险**：MEDIUM

```

(21a) M = [ W    −Jᵀ   −∇Γ ;

            ∇Γᵀ   0     0   ]

> **方框：为什么 (21b) 第三项必须是 `+log(Γ−1)`**

> `b₃ = −∇Γᵀq̇ = +log(Γ−1)`。
> 论文印的是 `−log(Γ−1)`，与本式相反，也与它自己的 (17d) 相反。官方代码写 `lambda*log(Γ_−1)`：

### P5-T08 · SCA 约束进入 QP 的安全闭环（低维）

- **优先级**：`MINIMUM_ESSENTIAL` ｜ **标签**：`ORIGINAL`（约束结构）+ `ADAPTATION`（低维替代模型） ｜ **风险**：HIGH

**源方程**
```
(17d)  − ∇Γ^{ij}(q^{ij})ᵀ q̇^{ij} ≤ log( Γ^{ij}(q^{ij}) − 1 )     ∀(i,j)
(26)   ∇_q Γ = (∂Γ/∂f)(∂f/∂q)        ← 零填充嵌入到 d_Q 维
(16)   Γ>1 自由 / =1 边界 / <1 碰撞
(21a)(21b)  SCA 进入 M、b 的第三行/块（符号见 T05 方框）
```
(17d) 的语义：`Γ→1⁺` 时右端 `→ −∞`，等价于 `∇Γᵀq̇ ≥ −log(Γ−1) → +∞`，即**硬屏障**（必须朝自由侧
足够快地移动）。离散实现必须限幅，论文未讨论 —— 这条要写进局限。

**官方代码可用性**
`QP_IK_solver` 的 `M`/`b` 结构存在，但 `Gamma_ = 2`（常数）、`DGamma_ = 0`（零向量）且**从不更新**，
`get_gamma()` 只声明未定义 ⇒ **官方 QP 实际没有 SCA**（O9）。本任务的约束链路必须自建。

**低维替代模型的构造（关键设计）**
用 `T06` 的官方 2D CPSP 模型作为**学到的约束"神谕"**：
- 特征 `f = p_2(q) − p_1(q) ∈ R²`（两个体点之间的相对位置），与 2D 模型的训练特征**维度一致**；
- 于是 (26) 变成精确可写的链式法则：`∇_qΓ = (J_2(q) − J_1(q))ᵀ ∇_f Γ`，`J_k = ∂p_k/∂q`（`2×d_Q`）。
- `(17d)` 的 `∇Γ^{ij}` 通过零填充嵌入 `d_Q`（只有 `q^{ij}` 对应的列非零）。

这条设计的好处：**它真的用了学到的模型**（不是手写距离函数），并且 (26) 可以从头验证。
代价：2D 模型的绝对尺度与我们平面双臂的几何只有**解释性**对应，属 `ADAPTATION`。

**独立数学验证**
1. **链式法则**：`∇_qΓ` 与"对 `Γ(f(q))` 整体做中心差分"比较（`d_Q = 4` 时 FD 很准），
   相对误差 < 1e-6。
2. **符号判定（不依赖 FD）**：沿 `+∇_qΓ` 方向走一小步，`Γ` 必须**增大**；沿 `−∇_qΓ` 必须减小。
   这是纯解析判定，用来钉死 O3 的符号。
3. **约束激活的 KKT**：构造一个使约束恰好激活的构型，检查 `∇Γᵀq̇ = −log(Γ−1)` 且 `ν > 0`。

**正测试**
- P8.1 开启 SCA，双臂相向直线运动：`min_t Γ(t) ≥ 1`（容差 1e-3）。
- P8.2 约束激活率 > 0（若从不激活，说明约束没起作用，测试无意义）。
- P8.3 `∇_qΓ` vs FD 相对误差 < 1e-6；沿 `+∇Γ` 的 `Γ` 单调增。
- P8.4 `log(Γ−1)` 在 `Γ→1⁺` 时被限幅（记录限幅触发的次数），且限幅后仍保持 `Γ ≥ 1`。
- P8.5 关闭 SCA 时 `min Γ < 1`（对照组，与 P8.1 构成差分实验）。

**负测试**
- N8.1 **翻转 `∇Γ` 符号**：必须加速碰撞（`Γ` 更快跌破 1），证明符号敏感性。
- N8.2 `λ = 0`（官方默认）：约束退化为 `∇Γᵀq̇ = 0`，系统在梯度方向"卡死"，`min Γ` 不保证 → 必须红。
- N8.3 `(21b)` 用 `−log(Γ−1)`：约束把构型吸向边界 → `Γ` 单调下降，必须红。
- N8.4 去掉零填充（只填 `q^{ij}` 对应的 2 列，其余当成 0 但维度写错）：维度断言。
- N8.5 `Γ` 初值 < 1（已碰撞）：QP 应报不可行（`log` 负数），**不得**返回任意解。

**计算需求**：`d_Q = 4`（2 臂 × 2 关节），`d_n = 2`，`d_c = 1`；每次 QP `10–20` 维，
LVI 收敛 1e2–1e3 迭代；`2000` 步闭环 ≈ `5–20 s`。

### P5-T09 · FCL/距离型约束 QP（明确标注 ADAPTATION）

- **优先级**：`OPTIONAL_EXTENSION` ｜ **标签**：`ADAPTATION` ｜ **风险**：MEDIUM

**源方程**：**无对应论文式**。这是"用几何距离约束替代学到的 SCA 边界"的工程做法，
`references/P5_qp_coordination.md` 的原始设想就是这一条。

**官方代码可用性**：无。`common/` 里若有距离接口可作为工程参考，但不属于论文范围。

**独立数学验证**：与 `T08` **同场景、同控制器**，只替换约束来源（`Γ` → 有符号距离 `d(q)`）。
用解析胶囊体距离（`d = ‖p_2 − p_1‖ − (r_1 + r_2)`），梯度解析可得，可 FD 校验。

**正测试**：P9.1 最小距离全程 ≥ 0；P9.2 与 T08 的"机制有效性"同向（都避免了穿透）。
**负测试**：N9.1 把该结果当作"SCA 复现"—— **范畴错误，报告必须显式拒绝这一结论**（CSV 的 negative_test 原文）；
N9.2 `d` 的梯度符号翻转 ⇒ 加速穿透。

**计算需求**：与 T08 同量级，< 20 s。
**预期图与指标**：`t09_constraint_source_compare.png`（两条约束来源的对照曲线）；指标 `min_distance`、
`activation_ratio`、`solve_time`。
**科学保真度与局限**：纯 `ADAPTATION`。**任何时候不得与 T08 的结果合并成单一"SCA 复现"结论。**
它的价值是提供一个**强基线**：如果距离约束和学到的边界在玩具问题上表现相同，那论文的 SCA 在低维
就没有可测优势 —— 这个"无差异"本身是有信息量的结论，但只能作为**讨论**，不能作为**复现**。

**交付与判据**：`p5/impl/tasks/t09_distance_qp.py`、1 张图、`P5_T09_POST.md`；**10 项检查全绿**。
