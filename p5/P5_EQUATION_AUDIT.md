## 0. 方法与状态词表

### 0.1 三条判据

每条公式按三个维度独立判定，互不替代：

| 判据 | 问题 | 证据来源 |
|---|---|---|
| **T（Text）** | 论文的字面表述是否自洽、可无歧义转录？ | 300 dpi 页面裁切；与上下文、相邻公式、附录交叉验证 |
| **C（Code）** | 公开代码是否有对应实现？实现是否等价？ | 固定 commit 的源码逐行比对（见 `P5_OFFICIAL_CODE_AUDIT.md`） |
| **V（Verifiability）** | 能否在不依赖官方代码的前提下独立验证？ | 闭式解、KKT、有限差分、不变量、极限行为 |

一个公式可以 `T=自洽`、`C=无实现`、`V=可验证`——这正是 SCA 梯度链式法则 (26) 的处境，也是本次审计最有价值的一类结论。

### 0.2 状态词表（与 CSV 一致）

| 状态 | 含义 |
|---|---|
| `CODE_MATCH` | 公开代码与印刷公式等价（逐项对应） |
| `CODE_MODIFIED` | 结构一致但含论文未写的额外因子/机制 |
| `CODE_PARTIAL` | 只实现了公式的一部分（通常是"结构在、数值不在"） |
| `CODE_DIVERGENT` | 代码实现的是**另一个**表达式 |
| `CODE_IMPLIED` | 由另一条已实现公式退化得到，无独立代码 |
| `CODE_BUGGY` | 有实现但确定性错误 |
| `CODE_EXTERNAL` | 由随仓库打包的第三方工具完成 |
| `NO_PUBLIC_CODE` | 未找到任何公开实现 |
| `PROOF_ONLY` | 证明步骤，本就不应有实现 |
| `T?` 标记 | 字面存在歧义/不自洽，需在复现时裁决 |

### 0.3 阅读保真度声明

- 全部公式在 150 dpi 下通读定位，在 **300 dpi 下逐条裁切**确认上下标、正负号与括号范围；`pdftotext` 的输出只用于检索，不用于判定符号。
- 已确认的"易错字形"：`τ̇` 与 `τ`、`γ̇` 与 `γ`、`∇Γ` 与 `Γ`、`x^V` 与 `x^R` 的上标；式 (11) 末尾 `τ_ci ẋ_i^V` 的上标确为 `V`（非 `R`）。
- 不能确认的地方一律标注，不做"看起来合理"的补全。

## 2. 逐式审计（A：任务空间，式 1–15）

### (1) 拦截点可行性
- **原文**：`p({¹ξ₁^O,…,^{N_R}ξ_{N_R}^O}; W) = Π_j p_j(^jξ_j^O; θ_j^W)`，`δ = Π_j δ_j`；若 `δ < p(...)` 则该点为可行拦截点，多个则取离末端最近者。
- **判读**：T=自洽。依赖"各机器人工作空间统计独立"这一建模假设（论文明确写出）。
- **代码**：`LPV.cpp` 的 `GMM::PDF` 提供单臂似然；`multiarm_ds::CalculateCatchingprobability` 用**盒式位置约束**（`minPos/maxPos`）做判据，而不是 (1) 的似然乘积。→ `CODE_PARTIAL`。
- **V**：可验证（对已知 GMM 计算乘积似然，与逐项相乘比较），但**无官方 workspace 模型可用**（只发布了一组单臂 `IIWA_workspace_Model*.txt`）。
- **风险**：低（D082 不把拦截点判定作为核心）。

### (2) 单臂 LPV 动力学
- **原文**：`ẋ_i^R = τ̇_ci(x_i^V−x_i^d) + τ_ci ẋ_i^V + A_i(θ_i)(x_i^R − x_i^d − τ_ci(x_i^V−x_i^d))`
- **判读**：T=自洽，三项角色清晰（见主报告 §3.2）。
- **代码**：`multiarm_ds.cpp::calculate_ATX()` + `calculate_robot_next_state()` 逐项对应（`DX_ = tau_*DX_d_ + ATX_`）。→ `CODE_MATCH`（全库最高保真度）。
- **V**：可直接数值验证：给定 A(θ)、τ、x^V、x^d，比较手写右端与代码同式。
- **风险**：低。注意 `X_F_P_` 是**异步目标** `x^d`，`X_d_` 是**虚拟物体** `x^V`，命名与论文相反，读代码时极易搞反。

### (3) 仿射调度
- **原文**：`A_i(θ_i) = Σ_k θ_ik A_ik`
- **判读**：T=自洽。θ 的归一化由 GMR 保证（`0<θ_ik≤1`、`Σθ=1`），论文明确指出这不是额外约束。
- **代码**：`LPV.cpp::Calculate_A()`、`Calculate_Theta()`（先验×高斯后验，再归一化；`sum<1e-100` 时退化为均匀）。→ `CODE_MATCH`。
- **V**：可验证（θ 单纯形约束、A(θ) 的凸组合性质）。

### (4)(5) 定理 1 与 LMI
- **原文**：`lim ‖x^R − τx^V + (τ−1)x^d‖ = 0`，条件为 `P^R≻0, Q^R≻0, P^R A_ik + A_ikᵀP^R ≺ −Q^R, θ_ik≥0`。
- **判读**：T=自洽。论文明确"P、Q 只用于证明，从不在线计算"。
- **代码**：`NO_PUBLIC_CODE`（无 LMI 求解/校核；`SESODS_lib` 里的 LMI 是**学习**稳定 DS 用的，不是验证 (5)）。
- **V**：**可独立验证**：给定 A_ik，用 Lyapunov 方程求 P，再检查 `P A_ik + A_ikᵀP` 的最大特征值 < 0。这不需求解 SDP，属于充分性校核（若失败，不能反证 (5) 不可行——这一点必须在报告里写清）。
- **风险**：中。容易把"我构造的 P 满足"误说成"LMI 可行"。

### (6)(7) 两个极限
- **判读**：T=自洽，由 (2) 直接退化。→ `CODE_IMPLIED`。
- **V**：把 τ 设为 0/1 后与 (2) 数值对比即可。

### (8) 同步分配动力学 ★
- **原文**：`τ̇_ci = τ_ci(1−τ_ci)G(ξ^O,ξ̇^O)/k`，`G = −ξ̇^Oᵀ(ξ^O−ξ^O(T*))/(ε+‖ξ^O−ξ^O(T*)‖²)`，`τ_ci(0)=ε`。
- **判读**：T=自洽。logistic 结构使 τ 自动落在 (0,1)；`k` 在**分母**（k 越大越慢）。
- **代码**：`calculate_coordination_allocation()`：
  `Dtau = 10·τ(1−τ)·DX_O_(0)/‖ξ^O − ξ^V‖`，随后硬饱和 `τ∈[0.001,0.99]`。→ `CODE_DIVERGENT`。
  差异清单：(a) 只用物体速度的 **x 分量**，不是完整内积；(b) 分母是**到当前虚拟物体的距离**，不是到拦截点的距离 + ε；(c) 没有负号（符号约定由 `ξ^O−ξ^V` 方向承担）；(d) `k` 被折成常数 10（即 1/k=10 → k=0.1）；(e) 加了论文没有的硬饱和。
- **V**：**可完全独立验证**：G 为常数时闭式解 `τ(t)=1/(1+((1−τ₀)/τ₀)e^{−Gt/k})`；用它校验积分器与步长。
- **风险**：中。若把官方版本当"论文实现"，τ(t) 的切换时点会系统性偏早/偏晚。

### (9)(10)(11) 虚拟物体 ★★
- **原文**：(9) `ẋ^V = [γẋ^O+γ̇x^O+A^V x^V−γx^O+ΣU_i]/(1+Στ)`；(10) `U_i = ẋ_i^R − A_i(θ_i)(x_i^R−x_i^d−τ_ci(x_i^V−x_i^d)) − τ̇_ci(x_i^V−x_i^d)`；(11) 代入后 `ẋ^V = [γẋ^O+γ̇x^O+A^V(x^V−γx^O)+Στ_ci ẋ_i^V]/(1+Στ_ci)`。
- **判读**：T=**可转录但不自洽**（关键发现，详见 §4.1）。
- **代码**：`Update()` 在**拦截点相对坐标**下计算 `DX_V_INTERCEPT`，并用 `U_sum = Στ·U`（`U_=−ATX_`）取代 `Στẋ^V`。→ `CODE_DIVERGENT`。
- **V**：可验证（代数恒等式残差 + 两条实现的轨迹差异）。
- **风险**：**高**。这一条决定"同步行为下虚拟物体是否被臂拖动"。论文方程说"不拖动"，官方代码说"拖动"。

### (12)(13) 定理 2
- **判读**：T=自洽（条件同 (5) 的形式）。
- **代码**：`NO_PUBLIC_CODE`。
- **V**：可验证（Lyapunov + 特征值）。

### (14) Remark 1
- **判读**：T=自洽，是 (7)+(12) 的合成。
- **V**：作为数值极限检查（τ=1 且 γ→1 时应同时收敛位置与速度）。

### (15) 协调参数 γ ★
- **原文**：`γ̇ = (1−γ)/(‖ξ^O(t)−ξ^O(T*)‖+ε)`，`γ(0)=0`。
- **代码**：`calculate_coordination_parameter()` 用**代数式**：`γ = e^{−0.1‖ξ^O(T*)‖²}`，`γ̇ = −2 ξ̇^{O,T}ξ^O(T*)/e^{‖ξ^O(T*)‖²}`，再夹到 [0,1]。→ `CODE_DIVERGENT`。
  另：`calculate_coordination_parameter()` 在 `Update()` 中**先于** `X_O_INTERCEPT_` 更新调用，因此用的是上一步的拦截向量（一步滞后）。
- **V**：可验证（ODE 积分 vs 代数式，两者在物体远处差别极大：ODE 里 γ 单调趋 1，代数式里 γ 随距离指数衰减）。
- **风险**：中高。γ 直接决定虚拟物体"多快放弃预测、贴近真实物体"。

## 3. 逐式审计（B：集中式 QP，式 16–23）

### (16) Γ 的符号语义 ★
- **原文**：`Γ<1` 碰撞；`=1` 边界；`>1` 自由。
- **判读**：T=清晰。但 §5.1 开头把"+1/−1"称为"非碰撞/碰撞"，§5.2 又改为"边界=+1、安全被过滤"——**两处表述冲突**，以实现为准（边界为正类）。
- **代码**：分类语义成立（数据集 `y=−1` 碰撞、`y=+1` 边界）；但"Γ 的值等于 1 时在边界上"**没有实现**：官方 CPSP 模型 `bias=0`，其决策边界是 `Γ=0`。→ `CODE_PARTIAL`。
- **V**：可用标签一致率检验，但"Γ=1 等值线 = 碰撞边界"这一命题**在官方模型上不成立**，除非做仿射标定。
- **风险**：**高**（O7）。QP 用 `log(Γ−1)`，若 Γ 在自由区的典型值 <1，则直接 NaN。

### (17a)(17b)(17c) QP 的三个部分
- **原文**：`argmin ½q̇ᵀWq̇`；`J(q)q̇ = ξ̇^R`；`θ̇⁻ ≤ q̇ ≤ θ̇⁺`。
- **判读**：T=自洽。决策变量是**速度**（正文 "velocity-level constraints"）。
- **代码**：`W_`、`J_`、`b_` 的块组装可读；盒约束在 `Construct_boundaries_vel()`。但 QP 的实际求解依赖**未发布**的 `cvxgen/`。→ `CODE_PARTIAL`。
- **V**：**可完全独立验证**（解析 KKT、SLSQP、LVI 三条路互校）。
- **风险**：低（数学层面）；中（工程层面，见 O11）。

### (17d) SCA 线性不等式 ★★
- **原文**：`−∇Γ^{ij}(q^{ij})ᵀ q̇^{ij} ≤ log(Γ^{ij}(q^{ij}) − 1)`，对所有机器人对 (i,j)。
- **判读**：T=自洽，但有两个隐含约定论文没写：
  1. `∇Γ^{ij}` 是**臂对联合空间**（`d_qi+d_qj` 维）的梯度，而 (21a) 里的 `∇Γ(q)` 是**全系统** `d_Q` 维——需要零填充嵌入，论文未说明（代码用全长 `DGamma_`，隐含嵌入）。
  2. `log(Γ−1)` 在 `Γ→1⁺` 时 → −∞，等价于无穷硬屏障；离散实现必须限幅，论文未讨论。
- **代码**：M 的行/列结构存在，但 `Gamma_=2`、`DGamma_=0` 且**从不更新**；`get_gamma()` 只声明未定义。→ 实际是**死代码**（`CODE_DIVERGENT`）。
- **V**：可验证（构造解析 Γ，检查激活/非激活两种情形下的 KKT）。
- **风险**：**高**。这是"论文的核心贡献在公开代码中不可用"的直接证据。

### (18) 限位→速度界
- **原文**：`θ̇⁻ := max(μ(q⁻−q), q̇⁻)`，`θ̇⁺ := min(μ(q⁺−q), q̇⁺)`。
- **判读**：T=自洽。注意正文把 `q^±` 与 `q̇^±` 统称为"conservative bounds on positions and velocities"，措辞含混，但公式本身无歧义。
- **代码**：`Theta_minus = max(mu*(eta*L_q − q), L_Dq)`，`Theta_plus = min(mu*(eta*U_q − q), U_Dq)`，`mu=20, eta=0.9`；另有 `Super_constraint` 的 sigmoid 平滑（论文未描述）。→ `CODE_MODIFIED`。
- **V**：可验证（给定 q 单调逼近限位，检查 `q(t)` 不越界；这是"离散时间下是否真的不越界"的直接检验）。
- **风险**：低-中。`eta=0.9` 的收缩会让可行域比论文更保守。

### (19)(20) LVI 与投影动力学
- **原文**：`P_Ω(u−(Mu+b))−u = 0`；`u̇ = (I+Mᵀ)(P_Ω(u−(Mu+b))−u)`。
- **判读**：T=自洽。**注意括号位置**：是 `(I+Mᵀ)(P(·)−u)`，不是 `(I+Mᵀ)P(·)−u`。这一点极易抄错，且会改变不动点之外的全部动力学。
- **代码**：`Solve()` 的 Dynamical 分支逐字对应（含括号位置）。→ `CODE_MATCH`（全库第二高保真度）。
- **V**：**可完全独立验证**（与 KKT 解比对 + 被动性检验）。

### (21a) 块矩阵
- **原文**：`M = [[W, −Jᵀ, −∇Γ],[J,0,0],[∇Γᵀ,0,0]]`。
- **代码**：五个块逐一对应。→ `CODE_MATCH`。
- **V**：可验证（手工组装 vs 代码打印，逐元素比较）。

### (21b) 右端项 ★★
- **原文**：`b = [0; −ξ̇^R; −log(Γ−1)]`。
- **判读**：T=**不自洽**（详见 §4.2）。按 KKT 推导，第三项应为 `+log(Γ−1)`。
- **代码**：`b_(last) = lambda*log(Gamma_−1)`，`lambda` 是**未初始化**的成员。→ `CODE_DIVERGENT`（方向对、参数缺）。
- **V**：可用 KKT 反解验证（给定激活约束，检查 `∇Γᵀq̇` 的符号）。
- **风险**：**高**。符号错 → 约束把构型"吸"向边界；`λ=0` → 禁止沿梯度方向的任何运动（系统卡死）。

### (22) 逐元素投影
- **原文**：三分支饱和。
- **代码**：`Solve()` 内联版本正确；但成员函数 `Omega_projector()` **计算了 `output` 却 `return Input;`**。→ `CODE_BUGGY`（当前主路径未调用该函数，故未暴露）。
- **V**：单元测试即可（输入越界值，检查输出被裁剪）。
- **风险**：低（不影响论文数学），但作为"官方代码不可盲信"的证据必须记录。

### (23) 原始-对偶盒
- **原文**：`u⁻=[θ̇⁻;−∞;0]`，`u⁺=[θ̇⁺;+∞;+∞]`。
- **代码**：`Theta_minus/plus` 入前 `d_Q` 位；对偶段 ±1e5（或 sigmoid）；`ν` 下界 0。→ `CODE_MATCH`。
- **V**：可验证（`ν≥0` 是互补松弛的符号，检查收敛后 `ν` 的符号即可）。

## 4. 逐式审计（C：SCA 学习，式 24–28）

### (24) RBF-SVM 决策函数
- **原文**：`Γ(f) = Σ α_n y_n exp(−‖f−f_n‖²/(2σ²)) + b`。
- **代码**：`SVMGrad` 的 MATLAB 与 C++ 实现均一致，`λ=1/(2σ²)`。→ `CODE_MATCH`。
- **V**：可验证（与官方模型 + 官方测试点复算 ACC/FPR/TPR）。
- **风险**：低（数学），**高**（参数语义，见 §4.4）。

### (25) 特征空间梯度
- **原文**：`∇_fΓ = −(1/σ²)Σα_n y_n e^{…}(f−f_n)`。
- **代码**：`−2λ·k·(x−x_s)`，与 `−1/σ²` 一致。→ `CODE_MATCH`。
- **V**：中心差分校验（相对误差应 ~1e-7 量级）。

### (26) 链式法则到关节空间 ★★
- **原文**：`∇_qΓ = (∂Γ/∂f)(∂f/∂q^{ij})`。
- **判读**：T=自洽。第二个因子是 `(3d_qi+3d_qj)×(d_qi+d_qj)` 的运动学雅可比。
- **代码**：**不存在**。`SCA-Boundary-Learning` 全库 grep 无 Jacobian；`QP_IK_solver` 的 `DGamma_` 从不赋值。→ `NO_PUBLIC_CODE`。

## 6. 五个高危条目的深度分析

### 6.1 O1：式 (11) 的自消

把 (2) 代入 (10)：

```
U_i = [τ̇(x^V−x^d) + τẋ^V + A(·)] − A(·) − τ̇(x^V−x^d) = τ_ci ẋ_i^V
```

代回 (9)：

```
(1+Στ) ẋ^V = γẋ^O + γ̇x^O + A^V x^V − γx^O + Σ τ_ci ẋ_i^V
```

两端 `Στẋ^V` 相消 →

```
ẋ^V = γẋ^O + γ̇x^O + A^V(x^V − γx^O)          ……(36)
```

**结论**：(11) 不是独立方程，而是恒等式；虚拟物体动力学与 τ 无关。这与 App.D 开头完全一致。

**科学含义**：τ 只作用于机器人侧（(2) 的结构变形），不作用于虚拟物体侧。因此"臂拖动物体"的说法不成立；同步的实现机制是"臂去追物体"，而不是"臂与物体互相牵引"。

**对复现的处置**：
1. 在报告中并列三个版本：`PAPER_EQ11`（照抄，会退化）、`PAPER_EQ36`（化简形式，论文证明所用）、`OFFICIAL_UPDATE`（代码实现，含 `U_sum`）。
2. 用随机状态做恒等式残差检验，把"照抄 (11) 必然退化为 (36)"变成可复现的数字证据。
3. 明确禁止：不得只实现官方的 `U_sum` 版本并声称"复现论文 (11)"。

### 6.2 O3：式 (21b) 的符号

QP 的 KKT 条件（记不等式 `g(q̇) = −∇Γᵀq̇ − log(Γ−1) ≤ 0`，乘子 `ν ≥ 0`）：

```
Wq̇ + Jᵀη − ∇Γ ν = 0 ,  Jq̇ = ξ̇^R ,  ν(−∇Γᵀq̇ − log(Γ−1)) = 0
```

在约束**激活**时 `ν>0` ⇒ `∇Γᵀq̇ = −log(Γ−1)`。

LVI 的第三行是 `∇Γᵀq̇ + b₃ = 0`，因此必须有 `b₃ = +log(Γ−1)`。
（若按标准 LVI 记号取 `C=∇Γᵀ, d=−log(Γ−1)`，则 `b₃=−d=+log(Γ−1)`，结论相同。）

论文 (21b) 印的是 `−log(Γ−1)`，与之相反。**这是论文内部的排版/符号错误**，不是我的转写错误：因为 (17d) 与 Fig.5（"∇Γ pushes the robot configurations away from the boundary"）都要求沿 +∇Γ 方向为正。

官方代码 `b_(last)=λ·log(Γ−1)` 方向正确，但 `λ` 未初始化：
- `λ=1` → 与 (17d) 一致；
- `λ=0` → 退化为 `∇Γᵀq̇=0`，即禁止任何沿梯度方向的运动（会"卡死"在边界附近）；
- `λ<0` → 方向反转，构型被推向碰撞。

**对复现的处置**：把 `λ` 提为显式参数，用"沿 +∇Γ 移动必须使 Γ 增大"这一解析判据做正/负测试（P5-T05/T08），并在报告中注明论文 (21b) 的印刷符号有误。

### 6.3 O7：Γ=1 的标定缺失

论文用 `log(Γ−1)`，隐含"自由区 Γ>1"。但：
- 官方 CPSP 模型 `bias=0`，svm_perf 的决策函数零水平才是分类边界；
- 官方 exact 模型 `rho=−3.5749`（libSVM 中 `b=−rho≈+3.575`），也没有把边界标定到 1。

因此把官方模型直接代进 (17d) 会得到 `Γ` 在 0 附近游走 → `log(Γ−1)` 无定义或复数。

**可能的标定**（都需要在复现中验证，不能凭猜）：
- `Γ̃ = 1 + s·f(x)`，`s>0` 使边界落在 `f=0`；
- `Γ̃ = exp(s·f(x))`，边界落在 `f=0` 且保证 `Γ̃>0`；
- 或者直接改写约束为 `−∇fᵀq̇ ≤ log(ε + s·f)`（等价于把 log 的零点移到决策函数零点）。

**处置**：P5-T07 必须在报告里给出"采用哪种映射、依据是什么、误差多大"，并把无法唯一确定的部分标为 `ADAPTATION`。

### 6.4 O8：σ 与 λ 的语义

| 记号 | 定义 | 官方模型的字段 |
|---|---|---|
| 论文 `σ` | 核宽，`k = exp(−‖·‖²/(2σ²))` | 无直接字段 |
| `λ` | `1/(2σ²)` | svm_perf 模型文件 `-g`；`.mat` 里的 `gamma` |

官方 `NewIIWASetup-Feb18-SparseModel.mat`：`gamma=3.3` ⇒ `σ≈0.389`；`2d_example.mat`：`gamma=50` ⇒ `σ≈0.1`。
若把 `gamma` 当 `σ` 用，`1/σ²` 会小 1–2 个数量级，梯度几乎消失（避碰失效）——这是"看起来能跑、其实没约束"的典型故障。

### 6.5 O10：(26) 的实现缺口

`∇_qΓ = ∇_fΓ · J_f(q)`，其中 `J_f` 是"关节三维笛卡尔位置"对关节角的雅可比。要在 FR3 上做，需要：
1. 球心在连杆上的固定变换（论文/代码用 DH + 固定偏移）；
2. 每个球心位置对 7 个关节的解析导数（`J_v` 的前三行即可）；
3. 把两臂的 `J_f` 按列拼接成 `(36)×(14)` 的块。

公开代码三样都没有。这是 C 组**必须自写、且必须用有限差分独立校验**的部分，也是"是否真的复现了 SCA"的判定点。

## 8. 审计结论
