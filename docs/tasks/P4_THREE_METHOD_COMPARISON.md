# P4 原论文三种闭链规划方法复现及统一对比实验

日期：2026-10-13。研究顺序：P4（RSS/PCS/NR三法真实比较）→ P2 → P3 → P5 → P1；最后再研究场景适配与算法小改。

## 科研问题

Sintov, Borum, Bretl (2018) 原论文比较了三种方法：RSS（随机奇异构型采样）、PCS（被动链切换）、NR（牛顿数值投影），这些方法与RRT、双向树、SBL等规划器组合。**必须实现三个方法，获得我们自己的真实对比数据**，不再只介绍RSS/PCS原理或援引论文表II当作我们实测结果。

2. 阅读作者 `CKCplanning@909bd72fff778aca8682c96f9eb86ae4eb75557b` 中相关实现作为参照，检查许可证/可复用边界，**不直接将作者代码当成自己复现的成果**。
3. 先审核模型可行性：RSS/PCS可能依赖主动-被动链划分及多分支解析或数值逆解。优先采用论文相应的机构或可科学论证的等价最小闭链机构进行统一实验。**不得因为已有FR3路径就强行在FR3上伪造PCS的多被动链切换或RSS的奇异采样**。

## 任务二：三方法核心软件

- RSS：实现论文要求的奇异构型采样与跨逆解分支的连接机制，证明采到的候选满足机构的真实约束和奇异性定义，而不是随机选取近限位姿态。
- PCS：实现论文规定的不同被动链划分及切换，证明切换前后构型仍满足闭链约束、逆解分支/局部连接资格；没有可用的多链划分就先报告阻塞，不伪造PCS成功。
- NR：复用此前经验证的NR数值投影和RBS/搜索思想；在统一机构上的适配差异应明确说明并单独做数值验证。先前双FR3实验可作为历史软件正确性证据，不能直接与新的RSS/PCS异模型对比。
- 共享：同一规划框架中统一采样、局部连接、碰撞、路径输出、计时和日志。不得仅仅分别编写不同控制器后用不同场景对比。
- 论文若未公布全源码，可在保留原公式/约束的前提下补齐软件实现；每一处补全标记为“根据论文实现”“必要数值补全”“与原文不同”。

最低要求：至少选择一个原文代表性闭链规划环境（可增加第二个困难环境，预算事先登记），三方法运行完全相同的测试协议；只统计实际跑过的实验。

- 随预算或环境复杂度的性能差异，若有对应原文数字则在单独表中对照，**不可比项写明不可直接比较**；

需保存三种方法各自的原始实验文件、固定种子、版本、参数、失败及成功全量记录；每张图标记“原论文数据”或“本次复现实测”，不挪用原文图表充当本次测试。
