已知数值风险：observer原Eq18 Euler与高刚度模式不匹配，线性化存在快模态；但尚无反事实数值对照，不能唯一归因于Euler，其他可能包括 C 静态偏置、接触近似、异步Q解释、P0/滤波重置、原惯量和机器人执行器缺失。请先做**只读根因分析**：首次估计偏离时刻、innovation、F/P与接触误差、已应用U、仿真时钟一致性、预测/更新竞争解释。将原数值模型与高精度参考在相同物理状态和输入的短时见证中对照；科学方法改变/额外模型假设须冻结新协议，不能偷偷改原accepted版本后把新数值当原实验。

必须分出以下可鉴别的最小实验及对应控制对照：
