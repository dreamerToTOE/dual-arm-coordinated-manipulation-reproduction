## 统一执行标准

1. 完整阅读目标原论文，并核对所有属于**核心贡献**的数学模型、公式、流程、必要参数和作者代码。建立原创文义务与批准算法范围的映射：`ORIGINAL/PAPER_CLAIM`、`ALGORITHM_REQUIRED`、`HARDWARE_OR_FULL_TASK_OUT_OF_SCOPE_D082`、`BLOCKED`。
2. 代码必须能**运行核心算法**，设定确定性输入数据、参考解析解/独立数值oracle、异常负例或收敛与约束误差。输出可复现日志/测试与至少1张真实数值结果图；单次组件pass不自动代表论文原实验全复现。
3. 旧真实失败、科学争议不随D082改判；同机制三次有记录修复仍失败，依D079做最小反例和OUR_IMPLEMENTATION/PAPER_RESOURCE/PAPER_METHOD_SUSPECTED/UNKNOWN归因，分版本修复而不悄改公式或验收门。
4. 算法级报告仍要求**正文详细数学讲解**、已实现核心代码及数值验收、原文任务级实验未做表、科研缺陷和双FR3适用性分析。不安排大规模随机种子、机器人动力学完整任务场景、真实视觉/触觉硬件、Isaac/ROS或原论文全部图表。Word/PDF和原文/批准/实做范围对照表仍需用户审核，且不能写原论文FULL。
5. 每篇要真实核对需要的数据/许可/版本，作者数据缺失可用公开或透明合成算例检验局部数学性质，但`RECONSTRUCTED`与作者实验准确数值不得混。

## P2 — De Simone等：位姿/内力解耦与视觉触觉状态估计

- 复用历史数学68/68、动力学70/70、组件35/35、因果时序2/2日志：这些真实单项合格，但3.948s IESEKF真实闭环估计状态超出形变域，**不许声称闭环成功或算法全验证**。
- 算法级必需：SE(3)右群运算、双柔性接触/内部力投影、pose和force控制律Eq19–21/25与不动点/零误差算例、IESEKF预测/观测更新/协方差的解析或高精度小步oracle。可单独诊断不稳定来源，真实plant/估计结果分开。没有必要恢复95s exp1–exp4、四物块装配、Fig9真滑动及硬件传感链。
- 原Eq15/22几何疑义与已批准的spatial-free重建分栏；实值的短数值检查不证明大范围稳定，失败照实列。

## P3 — Lee等：插孔阶段控制与力位混合

- 按**原论文**核对阶段approach/search/align/insert、力位混合与扰动/重抓手部算法的真实公式和前置假设。不要将教科书通用控制器冒称论文原实现。
- 在简单线性/刚体接触数学例子中输入位置/接触力/估计扰动，检查每阶段模式和控制输出；列成功与失败/触碰边界，画受控误差或力的**数值**曲线。
- 不做双机器人+灵巧手全套装配硬件/高保真MuJoCo，仅原论文核心有可复现公式与算法的部分；手部算法若依赖缺失的开源数据，应详列未实现，不能悄删创新。

## P5 — Salehian等：多臂协调规划的优化与数据驱动避碰

- 建立集中式QP，按论文变量/权重/同步和任务约束实现；用cvxpy/OSQP等独立求解交叉检查原始-对偶残差/约束余量、可行与无解分支、限位。原文是否仅限QP形式需先核对。
