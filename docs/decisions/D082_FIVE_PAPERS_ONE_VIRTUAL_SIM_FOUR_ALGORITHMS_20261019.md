## 三、P1/P2/P3/P5算法复现的工作流

1. 各篇**阅读全文**、图/式/算法段、开源代码/依赖，列出“必需核心算法模块”与“仅用于原论文物理实验的系统模块”；不能因为四篇不做任务级仿真而把核心算法创新删掉。

3. 若原文算法依赖不可获取的训练数据、标定或专用模型，先查作者资源与可复现算例，必要时用明示的数学合成数据证明局部机制，仅声明“算法级重建”，不得声称原文任务/系统完整效果复现。
4. 每篇结题仍要交完整中文**算法复现报告**（核心公式推导、代码、数字/差分/参考求解结果、失败与缺失的原文系统实验，真实可运行命令）、原创证据图及“原论文 vs 实际算法覆盖”对照表，另有双FR3借鉴章。四篇不必做轨迹任务/实物/整篇图表对比，不得因为缺这些实验而阻塞算法级合理结题；“算法级通过”与“原文FULL”分开。
