## 解释和原文差距

受控并集176→180的变化证明在这一冻结有限总体中，第二个分划补足了4个p0局部连接失败；m≥2同为180，不能据此外推复杂障碍/全流形/规划速度优势。端点条件于13条历史成功轨迹，配对共享端点，且距离仅到2.70rad，分母不是原文均匀总体。结果采用固定有限样本的精确描述率，不附独立Bernoulli总体置信区间。空距离bin没有连接曲线，图中列出实际分母。

原文Fig3下图为Bi-RRT规划时间，本次成本图是**局部连接检查时间**。本次未新增NR曲线，也没有原m20；重建20R仅17个非零连续3R图表，本次与旧实验一致只请求最大前缀m16。此项不支持PCS优于NR或兼容fixed-PCS的全局性能结论，也不把这些局部候选当最终规划解上的连续partition切换。
