# P2-T01 式(18) 数值传播裁决 — 只做数学分析与方案设计

**结论**：`PAPER_LITERAL_EULER` 在本实现的物理参数下，于论文的 4 ms 滤波周期**不稳定**（快模态放大 7.73 倍/步）；
这不是估计器逻辑错误，而是"连续模型 + 显式 Euler 离散"与该模型刚度不匹配。建议以 `STABLE_DISCRETIZATION_V1`
并列一个新传播格式（**不替换**旧基线），并同时修改状态转移矩阵与过程噪声，保持测量更新时序不变。
本文件**不含**任何新仿真、不改任何源码、不重跑闭环。

数据：`p2/reviews/T01_DISCRETIZATION_MODES.json`（`p2/tools/t01_discretization_modes.py` 生成，纯闭式，0.04 s）。

## 1. 快模态来自哪里

`results/20261014_P2_stage2_numerical_audit01/` 在**闭环之前**用 42 维右误差 Jacobian 的实特征值给出：

| 对象 | 最快连续实特征值 | 次快 | 复模态 | Euler 临界步长 `2/|λ|` |
|---|---:|---:|---|---:|
| A（exp1–exp4 用） | **−2183.07 s⁻¹** | −352.58 | −83.54 ± 97.74i | **0.916 ms** |
| C（Fig.8/9 用） | **−9335.81 s⁻¹** | −452.83 | −145.59 ± 105.58i | **0.214 ms** |

该模态由接触刚度和阻尼与（小）等效惯量共同决定，属"刚性软接触"模态；其精确物理归属留待 T03 用谱分解与受扰运动确认（审查意见要求，不在本轮做）。

旧失败案例保存的最后一次 3 ms 预测矩阵 `F` 的最大特征值为 **−5.547**，而
`1 + 0.003 × (−2183.07) = −5.549` —— 两者一致，说明失败时保存的正是这一模态的 Euler 放大。

## 2. 判据

对标量模态 `λ`，一步放大因子 `R(hλ)`；稳定要求 **`|R| ≤ 1`**。

| 格式 | `R(z)`，`z = hλ` | `z → −∞` | 性质 |
|---|---|---|---|
| 显式 Euler（论文式 18 字面） | `1 + z` | `−∞` | 条件稳定，`h < 2/|λ|` |
| 隐式 Euler | `1/(1−z)` | `0` | L-stable，但过阻尼 |
| 梯形 / Crank–Nicolson | `(1+z/2)/(1−z/2)` | `−1` | A-stable，非 L-stable |
| 矩阵指数 | `e^z` | `0` | 对 LTI 精确，L-stable |
| Euler 子步 `n` | `(1+z/n)^n` | 视 `n` | 条件稳定，`n > h|λ|/2`，耗散偏大 |

三点必须写进结论：

1. A 的 Euler 在 **1 ms 就已经不稳**（1.183），不只是 4 ms。
2. C 的 Euler 在 **plant 自己的 1/3000 步长**也不稳（2.112）——所以 Fig.8/9 用 C 时必须换传播格式，否则必然复现同类失败。
3. 子步 Euler 需要 `n > h|λ|/2`：A 在 4 ms 需 `n ≥ 5`，C 在 4 ms 需 `n ≥ 19`；且子步 Euler 的放大因子（A, 4 ms, n=5: 0.232）远小于真值（`e^{−8.73}=1.6e-4`），属于**过阻尼**，会用"额外衰减"换稳定。这不算更准。

## 4. 为什么不能只改状态传播

若只把 `Φ` 换成 `exp(hA)` 而保留 `Q_d = h·L Q_c Lᵀ`，则**在最快标量模态这一个方向上**：

- A，4 ms：精确 `Q_d` 只有 `hQ_c` 的 **5.73%**（该方向偏大约 17.5 倍）；
- C，4 ms：只有 **1.34%**（该方向偏大约 74.7 倍）。

**口径限制（2026-10-19 审查后更正）**：5.73% / 1.34% 只对**该固定标量快模态**成立，
**不是整块 42×42 `Q_d` 的统一比例**；其余模态（−352.6、−83.5±97.7i 等）比例各不相同，
整体比值必须按矩阵逐项计算。任何"Q_d 整体是 hQ_c 的百分之几"的说法都是错的。

后果：滤波在快模态方向被人为灌注过多过程噪声 → 卡尔曼增益偏大 → 估计方差虚高、对触觉残差过敏，
表现为"看起来更稳但精度与一致性都变差"，且会掩盖真实模型误差。因此 **Φ 与 Q_d 必须同源**。

**正确的 Van Loan 形式（原文档此处有误，已更正）**：

```
M h = [[A, G], [0, −Aᵀ]] · h ,   G = L Q_c Lᵀ
exp(M h) = [[Φ, S], [0, Φ^{−T}]]
Q_d = S · Φᵀ        ← 不是 S
```

**推导（标量检验，可直接复算）**：`A=a, G=q` 时
`S = q(e^{ah} − e^{−ah})/(2a)`，而精确离散噪声
`Q_d = ∫₀^h e^{aτ} q e^{aτ} dτ = q(e^{2ah} − 1)/(2a) = S·e^{ah} = S Φᵀ`。
若误用 `Q_d = S`，在 A 的 4 ms 情形（`ah = −8.73`）会得到约 `1.4 q`，而正确值约 `2.3e-4 q`，
**偏大 4 个数量级以上**，会直接毁掉滤波一致性。

**验收要求（T04 前必须做）**：
1. 逐项验证 `Q_d` 对称（`‖Q_d − Q_dᵀ‖∞ ≤ 1e-12·‖Q_d‖∞`）且半正定（最小特征值 ≥ −1e-12·最大特征值）。
2. 与 Lyapunov 方程 `A Q_d + Q_d Aᵀ = Φ G Φᵀ − G` 对照（残差按 `‖G‖` 归一）。
3. 与独立高精度数值积分（如 `mpmath` 或 `scipy.integrate.quad` 对每个矩阵元）对照，容差 1e-10 相对。
4. 噪声映射必须与同一坐标系一致：`G = L Q_c Lᵀ` 中的 `L` 与状态传播使用的右误差坐标相同，
   不得在 reset/运输 Jacobian 之间混用左右平凡化。

代价（实测）：`expm(42×42)=0.289 ms`，`expm(84×84)=0.682 ms`。若每步都用 84×84，95 s 案例仅 Q_d 就约
`0.68 ms × 39000 ≈ 27 s`，可接受但可优化；替代方案见 §5.3。

## 4ter. 指数型传播只是"局部线性化数值方法"

`δ = h φ₁(hA) f`、`Φ = exp(hA)` **不自动等于**非线性端点映射 `X ⊞ h f(X,U)` 的雅可比。
`exp(hA)` 是连续线性化的指数，而真实一步映射含 `f` 的二阶及更高项、`Exp/Log` 的曲率、
接触模式投影的非光滑性。因此：

1. 必须对**真实离散 map** 做右误差有限差分，验证 `Φ` 与 `∂map/∂(right error)` 一致（见 T04 门）。
2. 必须验证协方差在 reset/运输后的坐标一致性，而不是只看谱半径。
3. 小角度、接近 π、接触模式切换点、非正交/非正规 `A`、异常参数都必须单独测。
4. **`ρ(Φ) ≤ 1` 只说明线性化离散算子不放大，不是整个滤波器稳定或正确的证明。**


## 5. `STABLE_DISCRETIZATION_V1` 设计

**总原则**：同一连续 `f(X,U)`、同一 42 维右误差 Jacobian `A`、同一 `Q_c`、同一测量节拍；
**只改**离散传播算子与同源的过程噪声。旧 `PAPER_LITERAL_EULER` 保持可执行、可复现、可对照。

### 5.1 候选 A（推荐）：流形指数 Euler

```
δ   = h · φ₁(hA) · f(X_k, U_k)          φ₁(z) = (e^z − 1)/z
X⁺  = X_k ⊞ δ
Φ   = exp(hA)                            (42×42)
Q_d = S Φᵀ  (Van Loan, 见 §4)
P⁺  = Φ P Φᵀ + Q_d                      (Joseph 形式不变)
```

- 对 LTI 部分精确，L-stable；非线性部分为**局部二阶、全局一阶**（与 Euler 同阶，但不放大刚性模态）。
- `φ₁(hA)·f` 可用 `A⁻¹(Φ−I)f/h` 或 `expm` 的增广矩阵一次算出（42+42 维）。
- SE(3) 更新沿用现有右扰动 `X ⊞ δ`，姿态块仍是 `T·Exp(δ_θ)`，与 reset Jacobian 的坐标一致。
- **注意**：`exp(hA)` 与真实非线性一步 map 的雅可比不恒等，必须做右误差 FD 验证（§4ter、§8）。

### 5.2 候选 B（回退，最省改动）：误差坐标隐式中点

```
Φ = (I − hA/2)⁻¹ (I + hA/2)      (42×42 线性求解，无需 expm)
δ = h · f(X_k ⊞ δ/2) 的 Newton 解（24 个未知量，复用 plant 的 p2_advance 机制）
Q_d ≈ 0.5·h·(L Q_c Lᵀ + Φ L Q_c Lᵀ Φᵀ)   （二阶近似，需在 T04 声明误差）
```

- A-stable，`z→−∞` 时 `R→−1`（不衰减但也不放大），比指数格式略保守。
- 与已批准的 implicit plant 同一族方法，工程风险最低；C 在 4 ms 时 `R=0.898`，仍稳定（A 为 0.755）。

### 5.3 候选 C（仅诊断）：Euler 子步

```
n = ceil(h·|λ̂|max / 1.0)     |λ̂|max 由每步 A 的幂迭代或预存上界给出
Φ = (I + hA/n)^n
```

- 只用于证明"这是步长问题"，不作为正式方案：耗散偏大（A, 4 ms, n=5: 0.232），且 C 需 n≥19，代价高。

### 5.4 明确不采用

- 单纯缩小滤波周期（例如 1 ms）：A 在 1 ms 仍为 1.183；且改变论文的 4 ms 采样条件，属于改实验条件。
- 隐式 Euler 独占：过阻尼（4 ms 时 0.736 vs 真值 0.7465，看起来接近，但 A 在 1 ms 时 0.927 vs 0.9295 的偏差会累积成人工阻尼），只作对照。
- 提高 `Q_c` 或降增益来"压住"振荡：属于调参掩盖问题，禁止。

## 6. 测量更新时序：保持不变

- 预测仍在**每个心跳（4 ms）与每个新鲜测量时间戳**触发；更新仍按"同一时刻的包一次性消费"。
- 5 次内迭代、右 reset、Schmidt 冻结 C、Joseph 协方差、`stop_after_consecutive_nonconverged=3` 全部不变。
- 唯一变化：`prediction_linearization` 返回的 `F` 由 `I + hA` 改为 `Φ`，`Qd` 改为同源离散噪声。
- 因此新旧两版可以在**同一观测流、同一随机种子**下逐事件对齐比较（T04 的前置门）。

## 8. T04 的验证计划（本轮不执行）

1. **前置门（不闭环）**：对 A/C 两个 fixture，在 1/3000、1 ms、4 ms 下逐步记录 `ρ(Φ)`、`‖P‖`、`τ` 域余量，
   要求 `ρ(Φ) ≤ 1 + 1e-12`、`P` 保持 SPD、无 `COVARIANCE_ASYMMETRY`。**`ρ ≤ 1` 只是必要非充分条件。**
2. **端点 map 右误差 FD（新增，必须）**：对真实一步 map `X⁺ = X ⊞ h f(X,U)` 与候选 map
   `X⁺ = X ⊞ h φ₁(hA) f`，在 `X` 处做右扰动 `ε e_j` 的中心差分得到 42×42 雅可比，
   与代码返回的 `Φ` 逐项比较（相对容差 1e-6）；覆盖小角度、近 π、模式切换点、非正规 `A`、异常参数。
3. **协方差一致性**：`Q_d` 对称/半正定、Lyapunov 残差 `A Q_d + Q_d Aᵀ = Φ G Φᵀ − G`、
   与高精度数值积分对照；reset/运输后 `P` 仍 SPD。
4. **失败复现（因果性）**：用旧 `PAPER_LITERAL_EULER` 重放 3.948 s 前缀，必须复现同类停止（否则说明另有原因，停止并上报）。
5. **并行对照**：同一观测流/种子，跑 `PAPER_LITERAL_EULER` 与 `STABLE_DISCRETIZATION_V1`（标签 `ADAPTED_STABLE_PROPAGATION`），
   比较 ω/τ 估计误差、NEES、内力、命令；不得只报成功的一支。
6. **判据**：新格式至少通过 4 s 且不触发 pad 域门，才允许延长到 95 s；若仍失败，按"模型/观测问题"另立假设，
   不得继续调离散化。
7. **T03 的分工**：C 的显式 Euler 1/3000 不稳定（理论 2.112）与历史 native 隐式 plant 的 `ρ=2.73`
   是**两个独立观察**，必须分别验证，不得互相等同或互相解释。
8. **T02 提供的基线**：`p2/reviews/T02_MATH_AUDIT.json` 已对**现有** Euler 预测的 `F` 做了右误差 FD 对照，
   给出了当前 `F` 与真实一步 map 的逐项差异；T04 的稳定版必须做同样的测试，并与该基线并列。

## 9. 风险与不承诺

- 稳定传播**不修复**模型误差（Eq.15 替代、R̄ 近似、均质惯量、理想端点），也不保证论文定量一致。
- 换 `Q_d` 会改变滤波的有效噪声水平；**不得**为了"跑通"回头调 Q/R/KF/KP。
- 指数格式对非线性系统仍是一阶精度；若 T04 发现精度不足，应作为**新版本**讨论，不得静默升级。
- 若 A 的稳定版通过 4 s 而 C 仍失败，说明存在第二个问题（`ρ=2.73` 的 C 隐式步），必须分开归因。
