## 2. 42 维状态在流形上的结构

`X = (O, V, E1, E2, C, G1, G2)`，`O/E1/E2/C/G1/G2 ∈ SE(3)`、`V ∈ R⁶`，总自由度 42。
误差定义在**右扰动**：`X ⊞ δ` 对每个 SE(3) 块做 `T·Exp(δ_θ)`，`V` 线性相加；
`X₁ ⊟ X₂ = Log(X₂⁻¹ X₁)` 分块。`C = T^{b1}_{b2}` 在运输中冻结（Schmidt considered state）。
`Φ` 与 `Q_d` 都在**同一右误差坐标**下表达；reset 使用 `right_reset_jacobian`，不混用左/右平凡化。

## 3. 连续动力学与右误差 Jacobian

`f(X,U)` 为式 (13)–(16) 的 42 维向量场（native `continuous_linearization` 返回 `(f, A)`），
`A = ∂f/∂(right error)`。Python 解析版与 native AD 版在 T02/T03 已核对（差 ≤5e-10）。

## 4. 预测（两种模式）

- **A**：`δ_A = h f(x)`，`X⁺ = X ⊞ δ_A`，`Φ_A = I + hA`（按现有分块的 `Jr`/`Ad` 形式），
  `Q_A = h·(L_w diag(q)) L_wᵀ`（现实现）。
- **B**：
  ```
  [Φ_B, δ_B] = exp([[hA, h f],[0, 0]])        # 一次 43×43 指数
  X⁺ = X ⊞ δ_B
  Q_B = Van Loan(h, A, G),  G = diag(Q_c)
  ```
  `δ_B = h φ₁(hA) f` 对线性部分精确，L-stable；非线性部分为局部二阶、全局一阶。

## 5. Φ 与真实离散映射

**不假设** `Φ_B = exp(hA)` 等于非线性一步映射的真实 Jacobian。资格检查：
对 `map(X) = X ⊞ δ(X)` 做右误差中心差分
`J = ∂(map(X⊞εe_j) ⊟ map(X)) / ∂ε`，与 `Φ` 逐项比较；
要求 `‖J − Φ‖` 随 `h → 0` 以 **O(h²)** 下降（一致性），而不是要求逐位相等。
同时对 native 隐式 plant 的一步映射做同样 FD，作为第三方参考。

## 6. 过程噪声：连续与离散

`Q_c` 为连续谱密度（协议 `Q_cont = 0.004·Q_table` 的解释保持）。离散噪声用 Van Loan：

```
exp([[hA, hG],[0, −hAᵀ]]) = [[Φ, S],[0, Φ^{−T}]]
Q_d = S Φᵀ
```

必验：① 对称 `‖Q_d−Q_dᵀ‖∞ ≤ 1e-12·‖Q_d‖∞`；② 半正定（最小特征值 ≥ −1e-12·最大）；
③ Lyapunov 残差 `A Q_d + Q_d Aᵀ = ΦGΦᵀ − G`（按 `‖G‖` 归一）；
④ 与独立 Simpson 求积（80 区间）逐项比较（相对 1e-10）。

## 7. 协方差传播与 reset

`P⁺ = Φ P Φᵀ + Q_d`；两种模式各自用**自己的** `Φ` 与 `Q_d`，禁止混搭。
检查 `P⁺` 对称、半正定；不裁剪、不加 jitter、不改 `Q/R`。
reset：`P ← J_reset P J_resetᵀ`，`J_reset = right_reset_jacobian(δ)`（现有实现不变）。
