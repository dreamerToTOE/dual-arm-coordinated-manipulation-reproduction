## 2. `Φ_B = exp(hA)` 与真实离散映射 Jacobian 的差异（核心发现）

审查要求"不得直接假设 exp(hA) 等于新非线性离散映射的真实 Jacobian"。实测证实了这一点：

| 夹具 | \|f\| | 相对差（4 ms） | 相对差（1/3000） |
|---|---:|---:|---:|
| S1 静止（A 为平衡点） | 2.6e-9 | 2.8e-11 | 2.6e-11 |
| S2b 近平衡运动（仅速度） | 2.6e2 | 2.06e-3 | 3.8e-4 |
| S4 大姿态（双臂随动） | 4.7e2 | 8.92e-3 | 1.3e-3 |
| S2 运动+形变 | 1.14e3 | **1.35e-2** | 2.39e-3 |

- 差异集中在 `V̇` 行 × 物体位姿列（contact/gravity 对位姿的耦合随位姿变化的那一项），
  即 **∂A/∂x·f 的贡献** —— `exp(hA)` 不含它，任何只用 `A` 的格式都含不了。
- 绝对差按 **O(h²)** 收敛：h 减半时比值 1.6 → 1.9 → 2.5 → 3.0（A），1.56 → 1.77 → 2.08 → 2.47（C），
  渐近趋向 4；前置常数 ∝ |f|，故离平衡越远相对差越大。
- **模式 A 的 `F` 恰好不受此影响**（其 map 对 A 线性），这就是它 1e-10 的原因；
  但它的稳定性灾难性地失败。两种模式各有明确的、已量化的缺陷。

**裁决**：模式 B 的 `Φ` 记为**条件通过**——它是真实映射 Jacobian 的一阶一致近似
（绝对差 O(h²)，f=0 时精确），不是精确雅可比。下一阶段（3.948 s 观测流重放）必须
用重放实测该近似对估计精度的影响，而不是引用本表的相对差。

## 3. `Q_d`：naive Van Loan 在刚性夹具下数值失效（已修复）

| C，h=4 ms（\|λ\|h = 37） | naive（单次 84×84 expm） | stable（scaling/squaring，\|λ\|h ≤ 0.5） |
|---|---:|---:|
| 对称性（相对） | **8.0e-3** | 9.2e-17 |
| PSD（min/max 特征值） | **−1.3e-6**（负） | −1.1e-20（舍入级） |
| 与 stable 版的相对差 | **5.6e+5** | — |

原因：Van Loan 矩阵含 `e^{+37}` 级别的巨大项，`S Φᵀ` 乘积发生灾难性相消。
修复：把 h 分成 2ⁿ 个子步（\|λ\|h ≤ 0.5）并按
`Q(2h) = Φ(h)Q(h)Φ(h)ᵀ + Q(h)`、`Φ(2h)=Φ(h)²` 复合；
`Φ` 与单次 `expm` 相对差 2.2e-14（A）/3.2e-14（C）。成本 2.4–15.9 ms/次（仅 C 的 4 ms 超过 4 ms 预算，
生产实现需进一步优化，见 §7）。**未裁剪、未改噪声、未降刚度。**

## 5. 非正规性/短时放大

连续系统的 `‖exp(tA)‖₂` 在 t ∈ [h/4, h] 达到 **426–675**（A）与 **330–674**（C），
即存在强非正规瞬态放大。这解释了为什么即使 ρ=1（中性谱），短时误差也会被放大——
滤波器必须依赖测量更新来抑制，而不能只看谱半径。已作为 `nonnormal_amplification` 逐案例记录。
