## 4. 历史 `C ρ≈2.73`：已归因，**不是** native 隐式积分器

| 映射 | ρ（h=1/3000，旧夹具） |
|---|---:|
| **native 隐式中点（生产 plant）** | **1.000000** |
| 理论隐式中点 `(I−hA/2)⁻¹(I+hA/2)` | 1.000000 |
| `mechanics.midpoint_step`（**显式**中点预测-校正） | **2.730136** |
| 理论 Euler | 2.111936 |

- `z = hλ = −3.1119`；`|1+z+z²/2| = 2.730136` 与 `midpoint_step` 的 FD 谱半径**逐位吻合**；
  同一 z 的 `|1+z| = 2.111936` 正是 Euler 的 2.112。两者是**不同格式**，不能互相解释。
- FD 的 ε 从 1e-4 到 1e-7：native 恒为 1.0，`midpoint_step` 恒为 2.730136 → 不是差分伪影。
- 该点不是平衡点（`‖f‖=9.81`）；native 一步 Newton 收敛（1 次迭代，残差 4.05e-16）。
- 真实受扰 0.2 s：速度 0.545 → 0.0156（2.9%），与 ρ=1.0 一致，与 ρ=2.73 矛盾。
- **结论**：历史记录中的 "native 隐式中点 ρ=2.73" 是**标签错误**——它属于旧审计脚本调用的
  `midpoint_step` 显式实现；生产 plant 的隐式映射是中性（ρ=1）。**未修改任何旧代码或旧报告**，
  归因记录在本文件。
