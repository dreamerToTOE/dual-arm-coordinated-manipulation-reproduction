# P2-T04 EKF 对照协议（设计，本阶段不执行）

**目的**：为"标准 EKF vs 论文 IESEKF"的公平对照定义唯一有效的实验设计。
本阶段只写协议；任何运行需另行批准。

---

## 1. 公平性原则（不可协商）

两种滤波器必须共享**除传播算子与迭代结构之外的一切**：

| 项 | 要求 |
|---|---|
| 观测流 | 同一 `sensors.jsonl.gz` 事件序列（同一 tick、同一 kind、同一样本 id、同一值） |
| 初始化 | 同一 `initialization.json`（同一标定 C、同一 E1/E2/G、同一 V=0） |
| 噪声 | 同一 R 表、同一 `Q_c = 0.004·Q_table` 解释、同一随机流（无新增随机数） |
| 缺失/延迟 | 同一 robot2 视觉关闭（76 s）、同一 15 fps 缺帧、同一 delivery 时间戳 |
| 域门 | 同一 5 mm / 0.15 rad pad 门与同一 `PAD_DOMAIN_INVALID` 终止逻辑 |
| 时钟 | 同一 250 Hz 心跳 + 事件驱动预测、同一 delivery 时间戳 |
| 禁止 | 不得为任一滤波器单独调整 Q/R、增益、初值、容差或重置策略 |

## 2. 两种滤波器

| | 标准 EKF（对照） | 论文 IESEKF（主） |
|---|---|---|
| 传播 | 模式 A/B 各跑一遍（`PAPER_LITERAL_EULER` 与 `ADAPTED_STABLE_PROPAGATION_V1`） | 同左（与估计器同模式） |
| 更新 | 单次线性化（在先验处），`x⁺ = x ⊞ K r` | 5 次内迭代、固定先验、Joseph 形式 |
| 协方差 | `P⁺ = (I−KH)P(I−KH)ᵀ + KRKᵀ` | `P⁺ = J_reset P J_resetᵀ`（anchor 形式） |
| reset | 无（误差小） | 右 reset Jacobian |
| Schmidt C | 同样冻结（公平起见两种都冻结） | 同左 |

注：标准 EKF 也使用流形上的右误差坐标与 ⊞/⊟，仅去掉迭代与重锚——否则差异会混入
"迭代"与"坐标"两个因素，无法归因。

## 3. 指标

| 指标 | 定义 |
|---|---|
| 位置/姿态/速度误差 | `‖pos_hat − pos_true‖`、`‖Log(R_hatᵀ R_true)‖`、`‖V_hat − V_true‖`（真值只用于评分） |
| NEES | `(x̂⊟x)ᵀ P⁻¹ (x̂⊟x)`，按 42 维与分块（位置/姿态/速度）分别报告 |
| NIS | `rᵀ S⁻¹ r`（每次更新的创新一致性） |
| 一致性区间 | NEES 应落在 [n−3√(2n), n+3√(2n)]（n=42）的频率 |
| 失败率 | 域门触发、非收敛、SPD 失败的次数与时刻 |
| 停止时刻 | 各滤波器首次触发域门的 t |
| 运行时间 | 每次预测/更新的墙钟 |

## 4. 运行矩阵（待批准）

| 流 | 来源 | 长度 |
|---|---|---|
| R1 | 3.948 s 观测流重放（case 11 exp3 seed 7 的 sensors.jsonl.gz） | 到域门或 4.5 s |
| R2 | 重放至 95 s（需单独批准） | 95 s |

每组流 × {EKF-A, EKF-B, IESEKF-A, IESEKF-B} = 4 次运行；R1 共 4 次运行。

## 5. 判读规则

1. 若 IESEKF-B 在 R1 中通过域门而 IESEKF-A 失败 → 传播格式修正有效，可申请 R2。
2. 若两者都在同一时刻失败 → 传播不是根因，按 T01 §7 的备择假设继续。
3. 若 IESEKF-B 通过但 EKF-B 也通过 → 迭代不是关键，报告应如实说明。
4. 任何情况下不得为让某一方通过而修改 Q/R/域门/seed。

## 6. 本阶段不做

- 不实现标准 EKF 的更新循环（协议先行）；
- 不生成任何合成观测（重放必须用已保存的真实观测流）；
- 不运行 95 s 或 30 案。
