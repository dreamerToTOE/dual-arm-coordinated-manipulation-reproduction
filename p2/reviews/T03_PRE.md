## 1. 研究问题

1. A / B1 / B2 / C 在标称与 ≥2 个非平衡工作点的 42 维连续 Jacobian 快慢模态；
2. 五种离散格式（Euler / 隐式 Euler / 梯形 / 矩阵指数 / Euler 子步）在同一连续线性化下的稳定性；
3. **真实 native 隐式一步映射**（右误差 FD）的谱，与理论离散矩阵**分别报告**；
4. 历史 `C ρ≈2.73` 的复核与归因（不得与 Euler 的 2.112 混为一谈）；
5. 非平衡初值下的真实运动、接触/内力响应、能量、Newton 收敛、步长收敛阶；
6. B1/B2 的模型适用性与其 `ADAPTATION` 边界。

## 3. 方法与判据

### 3.1 连续谱（Stage S）
- 用 `native.continuous_linearization` 的 42×42 右误差 Jacobian（AD）为主，`estimator.continuous_linearization`（Python 解析）作交叉核对，两者逐项差异单独报告。
- 输出全部 42 个特征值（实部/虚部/模长），标注最慢/最快模态、复模态对、主导状态块（右特征向量按 7 个状态块求参与度）。
- 非正规性：`cond(V)`、`‖AAᵀ−AᵀA‖/‖A‖²`、最快模态的左右特征向量条件 `1/|lᵀr|`。

### 3.2 离散谱（Stage S）
- 同一 `A`、同一 `h`：Euler `I+hA`、隐式 Euler `(I−hA)⁻¹`、梯形 `(I−hA/2)⁻¹(I+hA/2)`、`expm(hA)`、Euler 子步 `(I+hA/n)^n`（n=4,8,16，诊断用）。
- `h ∈ {1/3000, 1/6000, 1/12000}`，另列 `1 ms`、`4 ms`。
- 判据：`ρ(Φ) ≤ 1` 为必要非充分；报告 `argmax` 模态。

### 3.3 真实一步映射（Stage S）
- 对 native `advance(..., h, 1)` 做右误差中心差分（42 列，ε=1e-6），得 `J_native(h)`；同样计算 `h/2`、`h/4`。
- 与 `expm(hA)`、梯形、隐式 Euler **分别列表**，禁止混合。
- C 的旧点额外做 ε ∈ {1e-4, 1e-5, 1e-6, 1e-7} 的收敛检查。

### 3.4 C ρ≈2.73 调查（Stage S）
1. 旧夹具（`conditional_sliding` 竖直 C）+ 原参数 + `h=1/3000` 复算；
2. 该点是否平衡：`‖f(X)‖` 与重力/接触残差；
3. 连续 Jacobian 是否有实部 > 0 的模态；
4. FD 的 ε 收敛（ρ 随 ε 的变化）；
5. 理论中点矩阵 vs native FD 的逐项差异与谱；
6. 李群坐标（右误差）、接触模式、Newton 残差/迭代是否影响；
7. 真实受扰积分：在该点施加同等小扰动，积分 0.2 s，看扰动增长/衰减，与 ρ 对照。

### 3.5 受扰运动（Stage P）
- A、C 为主；B1/B2 标 `ADAPTATION` 单列。
- 每个 object × 2 点 × {h, h/2, h/4}：积分 0.30 s（900/1800/3600 步），每 4 ms 采样。
- 记录：位姿、速度、`τ`、`hK/hB/h`、`internal`、能量（KE + PE + 弹性）、Newton 迭代/残差。
- 判据：不得以"终端速度→0"作为唯一合格依据；必须给时间对齐的误差曲线。
- 收敛：以 h/4 为参考，比较 h 与 h/2 在 t=0.10/0.20/0.30 s 的范数误差，`p=log2(e_h/e_{h/2})`；若不在渐近区（p 不稳定或为负），如实写"未观察到收敛阶"。

## 4. 预算与停止

| 阶段 | 上限 |
|---|---:|
| S 谱（含 C 调查） | **120 s** |
| P 受扰运动 | **240 s** |
| 合计 | **360 s**（硬上限，不滚动） |

单项失败（求解器不收敛、域越界、FD 失败）→ 记录 `FAIL` 并继续下一个案例，不重试超过 3 次。
