## 1. PASS/FAIL 门缺失 → 补充显式判定

原脚本只记录指标，无数值门。现按声明门重判 48 案：

- 稳定性 ρ_B ≤ 1+1e-6；Qd 对称 ≤1e-10、Lyapunov ≤1e-8；P⁺ 对称 ≤1e-10 且半正定。
- **结果：24 PASS（平衡/小角/模式边界）、24 CONDITIONAL（全部非平衡夹具）、15 初判 FAIL。**
- 15 个初判 FAIL 全部是 `ρ_B = 1.000002–1.000026` 略高于 1 的**非平衡夹具**。复核：这些夹具的
  连续线性化本身有 +0.01…+1.05 s⁻¹ 的正实部模态，`exp(max_Re·h)` 与 `ρ_B` 吻合
  （如 A-P1：exp(0.01×0.004)=1.00004 ≥ ρ_B=1.0000185）→ **离散格式忠实于（轻度不稳定的）连续线性化**，
  ρ>1 属夹具而非格式。最终判定改为 **CONDITIONAL**，并明确**不得宣称无条件渐近稳定**。

## 4. 协方差 trace 583.7/2.92 的对账

- **"583.7" 与 "2.92" 是 `max_eig(P_A)` / `max_eig(P_B)`，被 POST 误标为 trace**；
  其比值 583.7/2.92 ≈ 199.9 是**最大特征值比**，不是 trace 比。
- 存储的 `trace_ratio_b_over_a = 0.006740`（C/S2/4ms）→ A/B = **148.37**（该值用当时 naive Qd_b 计算）。
- 用当前 stable Qd 重构同一案例：`trace(P_A)=581.72`、`trace(P_B)=4.011`、比值 **0.006896 → A/B=145.0**；
  A/S1/4ms：trace(P_A)=40.70（不是 583.7）、max_eig=36.80。
- 两套 Qd（naive/stable）给出的 A/B 放大比 148.4 vs 145.0 —— 结论（A 放大 ~1.5e2 倍）不变；
  差异来自 Qd 离散化本身，已单独声明（§5）。

## 5. 噪声模型：两种模式**不是**同一离散化（必须声明）

| | 模式 A | 模式 B |
|---|---|---|
| 公式 | `Qd = h·Lw diag(Qc) Lwᵀ`（经 Euler 增量的 retraction Jacobian 映射） | `Qd = ∫ exp(A(h-s)) diag(Qc) exp(Aᵀ(h-s)) ds`（指数已含输运） |
| Qc 数组 | 相同 | 相同 |
| 离散噪声模型 | **不同** | **不同** |

同一 `Qc` 数组不等于同一离散噪声。两模式的协方差对比必须在"各自与其传播算子一致"的
意义下解读；POST 中"完全等条件"的说法在此更正为"同 Qc、不同离散化"。

## 6. `Φ_B = exp(hA)` 的定位

- f≈0 时是该 map 的精确雅可比（2.6e-11）；f≠0 时为 O(h²) 一阶一致近似
  （相对差 1e-3…1.4e-2 @4 ms，系数 ∝|∂A·f|）。
- **不得标记为非线性映射的精确 Jacobian**；不得以 ρ≤1 作为无条件稳定声明
  （非平衡夹具 ρ=1.000002–1.000026 属夹具正实部模态）。
