# P4 空间八分支 IK 的几何一致数值版本：独立推导与变更边界

本记录只审查源文件与推导，不包含任何新求解、编译或实验结果。实现为 `baselines/p4_full/geometry_consistent/spatial_ik_patch.py`；原作者快照、R1 原生失败、原始端点与成功判据保持原样。

## 1. 物理模型与局部数值常数

保留作者每一项连杆尺寸、机器人基座位姿、物体抓持变换及关节上下限。特别是 Comau 的基座旋转、VI 三边抓持矩阵和 `deg2rad` 仍使用原作者字面常数及原算法。不能把原 `PI`/`PI_` 全局替换成数学 π。

关节旋转是周期为数学 `2π` 的三角函数，因此 IK 内部的肩分支加 π 与关节主值换算应使用 `π=acos(-1)`。此处仅替换 `IKsolve_rob` 的局部几何计算；原八分支 `q3_sign` 和 `sign456` 序号保持不变。

## 2. 肩部有符号径向与肘部几何

先严格按照原始基座变换，将目标变换到机器人基座坐标，得到旋转 `R`、位置 `p`。末端 x 轴延伸为 `l5+lee`，腕心位置为

`p5 = p - (l5+lee) R[:,0]`。

选定肩分支后，`q1=atan2(p5_y,p5_x)+{0,π}`，采用数学 `2π` 化到主值。该肩分支内的有符号坐标为

`r = p5_x cos(q1) + p5_y sin(q1) - l1x`，

`z = p5_z - b - l1z`。

ABB 的对应量为 `l1x=0`、`l1z=l1`；其它步骤一致。`r` 的符号必须保留，不能将其替换为 `sqrt(r²)`，也不能在肩翻转后继续使用未翻转的径向。

定义 Comau `a=l3z, c=l3x+l4`，ABB `a=l3a, c=l3b+l4`，并记

`L=sqrt(a²+c²), alpha=atan2(c,a), D²=r²+z²`。

作者的肘部角分支可保留为

`cos(phi)=(D²-l2²-L²)/(2*l2*L)`，

`sin(phi)=q3_sign[s]*sqrt(1-cos²(phi))`，

`q3=-(atan2(sin(phi),cos(phi))+alpha)`。

仍保留原来负根号拒绝和原关节限位，不将超出可达域的目标投影回可达域，也不增加 NR 兜底。

## 3. q2 的完整象限恢复

根据独立逐段变换积，腕心位置满足

`r = l2*sin(q2) + a*sin(q2+q3) + c*cos(q2+q3)`，

`z = l2*cos(q2) + a*cos(q2+q3) - c*sin(q2+q3)`。

以 `a=L*cos(alpha), c=L*sin(alpha)` 展开，令

`A=l2+L*cos(q3+alpha), B=L*sin(q3+alpha)`，

得到

`r=A*sin(q2)+B*cos(q2)`，

`z=A*cos(q2)-B*sin(q2)`。

因此

`q2=atan2(r,z)-atan2(B,A)`。

这个表达式同时保留 `r<0` 和 `A<0` 的象限。原实现的 `sqrt(r²)` 与 `sqrt(1-sin²(beta))` 分别丢失了这两个符号；在 R1 保存数据中可分别解释肩内侧反射及负 A 象限残差。新式没有增加调参量，并继续使用原 q2 主值换算和原上下限。

## 4. 腕部 W 分解、数值消减与奇异代表

前三轴旋转为

`R03=Rz(q1)*Ry(q2+q3)`。

因此必须先计算

`W=R03^T*R=Rx(q4)*Ry(q5)*Rx(q6)`。

其可直接验证的独立元素关系为

`W00=cos(q5)`，

`W10=sin(q4)*sin(q5), W20=-cos(q4)*sin(q5)`，

`W01=sin(q5)*sin(q6), W02=sin(q5)*cos(q6)`。

非奇异时令 `u=hypot(W10,W20)`，保持作者分支符号 `s=sign456[branch]`，得到

`q5=atan2(s*u,W00)`，

`q4=atan2(s*W10,-s*W20)`，

`q6=atan2(s*W01,s*W02)`。

`hypot` 避免原 `sqrt(1-W00²)` 在接近 ±1 时的消减或因浮点舍入产生负根号。此处没有把输入旋转矩阵投影到 SO(3)，也不能据此把原截零目标的残差宣称为零。

当 `q5=0` 时，`W=Rx(q4+q6)`，关节对不唯一。取明确的 canonical representative `q4=0`，则

`q6=atan2(W21,W22)`。

原代码直接使用基座旋转 `R` 的 21、22 元素，仅在特殊前三轴姿态下等价。新版本在除去 `R03` 后求解。

`q5=±π` 时 canonical representative 可取 `q4=0`、`q6=atan2(-W21,-W22)`；在原来的 ±120° q5 限位开启时，此解仍被拒绝。不同索引可能在奇异层合并，不能将八个索引解释为八个互异姿态或完整连续奇异解族。

浮点零阈值单独声明为 `u <= 64*IEEE754_binary64_epsilon = 1.4210854715202004e-14`。这只是 W 分解的机器舍入判别，原 IK/投影的 `1e-5 mm`、`1e-5` 旋转矩阵门槛不变。旧的 `|q5|<1e-4` 置零和所有 `|qi|<1e-5` 置零均被取消。后续运行应保存 canonical 分支触发记录，而不能把其作为独立八解证明。

## 5. FK 连续性与双目标账本

ABB 的原 FK 不含逐元素截零，保持逐字不变。Comau IV/V/VI 仅移除最终的 3×4 矩阵 `|Tij|<1e-4` 置零循环，所有符号表达式和物理常数不变。

同一个保存的 qa 有两个应同时保留的对象：

1. R1 原作者 FK 输出并已保存的截零目标。这是历史输入，必须原样重新计分。
2. 同 qa 在连续物理 FK 下重算的目标。这个目标有独立标签，可检验精确解析几何，但不能代替前一个目标而追溯改判 R1。

两组应分别报告返回值、分支、求解关节、独立 FK 位置与旋转残差。不能筛去原截零矩阵的失败，也不能将这类失败混作物理模型不可达。
