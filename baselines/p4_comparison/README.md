# P4 RSS / PCS / NR：共同平面闭链规划壳

协议：[P4_THREE_METHOD_PRE_TASK](../../reports/P4_THREE_METHOD_PRE_TASK.md)，提交 `6d64b26`。
该实现是论文环境I同类的独立20R重建，不是缺少输入的原作者图2a精确副本，也不接入FR3/车厢/Isaac。
旧 `baselines/p4_closed_chain`、14q数据和所有历史失败记录均不修改。

## 接口及复用边界

`plan(model, env, method, seed, max_iterations, config=None)` 返回纯数据：双树、全部候选及局部边记录、
投影轨迹、完整离散关节路径、失败原因及实际计算时间。`method` 为 `RSS`、`PCS` 或 `NR`；
`env` 为已预声明环境名。没有发送指令、执行控制器或启动平台的代码。

已有TASK04的数学步骤 `q_next=q-J^dagger C`、SVD奇异值截断、独立位置/旋转收敛判断和失败留证据
是数值实现依据。历史模块固定14变量/6残差，不能直接适配本模型3x20雅可比；新模块显式完成维度适配，
不把补零或伪造自由度称为复用。旧FR3的“修正时必须rank6”是已记录的保守工程策略，不移植成平面模型要求。
本轮使用实际3x20全链Jacobian的Moore--Penrose截断伪逆，每步记录真实秩；rank0、非有限或停滞拒绝。
全闭链Jacobian的秩与某个被动3R的人工奇异不是同一概念。

RBS与双向树沿用此前已验证的算法组织思想，但所有策略在一个共享壳运行；不把普通MoveIt RRTConnect
加末端修正当闭链算法。共用真实模型资格判定、GEOS碰撞、节点/时间预算、叶分辨率和路径回溯。

## 三种投影与分支

- **RSS**：普通扩展及局部连接固定被动 `[16,17,18]`，按最近构型分支解析闭合。γ=.2请求精确奇异目标；
  固定中间角q17=0或π，再仅以不重叠 `[0,1,2]` 解析关闭整链、检查闭链/碰撞。这个p0只属于奇异样本生成器，
  不用于普通RSS边。每次请求最多32次；失败请求留证据，不暗中改成NR或普通采样。
- **PCS**：扩展随机选择预声明的p0/p16被动划分，按最近构型分支闭合；若该解析闭合失败，只尝试另一划分一次，
  对齐作者CBiRRT_PCS:150–247，保留两个投影记录，不调用NR兜底。局部连接只使用两端共同分支的划分，
  保存每条边实际采用的partition/branch及失败候选。遇到奇异端点，两个相邻分支都可连接，但中点仍全部验证。
- **NR**：20维整体投影至三维平面闭合约束，不调用解析IK替代。最多100次完整Newton更新、无阻尼、
  line-search、行权重或随机重启；周期角wrap，不进行关节clamp。位置1e-8m、角度1e-8rad分别验收。

对于已经满足原闭链阈值、且属于目标分支或精确奇异branch0的APC输入，保留原q而不再次求acos逆解。
这防止将精确0中间角仅因浮点acos舍入变成小非零角。它不是放宽判据：RBS仍检查该状态的原限位、残差、
真实碰撞和后续全部中点。普通异分支不能通过此早返回。

## 共同搜索与安全证据

两树交替；均匀ambient target、RSS额外原文奇异偏置；L2原始steer≤.6rad；稳定线性最近邻；
主动树extend一步、另一树最多25步connect。每条插入树的边都通过策略RBS；叶L2≤.05rad、depth≤20、
每条连接的所有划分尝试合计最多4096中点。节点≤2000，外层200或800，计算≤5秒。

当CONNECT已经进入另一树已验证节点的.6rad范围，保留那个精确目标q，由RBS选择真正共同分支，
不再用随机被动划分重新关闭并改变既有目标；两端及所有中点仍重检。该source-audited连接语义不构成目标偏置。
全q欧氏最近邻/steer和统一距离是事前锁定的公平比较设置，不冒充作者部分APC主动坐标度量的完全一致实现。

同一闭合状态的RSS/PCS“被动链人工奇异”允许作为branch0桥；并未采用作者RSS源程序中距奇异端点.75rad
即不再细查的捷径。加入树的所有叶端点都有资格记录，不把该证据称为连续扫掠无碰撞证明。

停止原因保留为 `START_REJECTED`、`GOAL_REJECTED`、`ITERATION_LIMIT`、`NODE_LIMIT`、`TIME_LIMIT`、
`INTERNAL_ERROR` 或实际投影/局部连接原因。仅有按原分辨率完成回溯与最终重检的路径才输出 `SUCCESS`。
耗时包括搜索、投影、GEOS、RBS及终止重检，不包括JSON序列化、gzip或文件I/O；不是机器人执行时间。
