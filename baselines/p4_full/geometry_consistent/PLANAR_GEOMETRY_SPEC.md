版本：v1，2026-10-15。状态：源码与推导准备完成，尚未编译、导入、运行或获得资格；正式规划调用数为 0。本文件是本项目独立实现的推导，不是作者修订代码，也不是对旧失败记录的改判。

## 固定模型与允许修复的边界

物理模型保持原作者 planar_ckc 固定提交 e5edcb58e151b78baca43dd4922bfe27a48388cd 的 20R 链、19 条单位连杆、地面向量 g=(7,4)、原始起终点以及原状态 chart。单位为作者归一化连杆单位，不是 mm。令 δ=3.1416，则完整闭环严格为

    F(q) = [Π(i=0…18) R(q_i) Tx(1)] R(δ-q_19) T(-7,-4) = I.

q_0…q_18∈[-δ,δ]，q_19∈[0,2δ]。δ 是物理编码器 offset，不能换成 π；三角恒等式、周期与反解的数学 π 使用真实 π。不会把 q_19 或其他坐标统一改写到 [-π,π]。状态距离仍是原 chart 上的字面欧氏距离，调用者不得用一次隐含归一化改变它。本文不重新解释作者另有的 qminmax=179.9/180*δ；该机械关节限制与运行 chart 是两件事，后续协议必须分别声明。

## 一般循环三因子分解

写 A_i=R(s_i q_i)K_i。前 19 个因子 s_i=1、K_i=Tx(1)；最后一个 s_19=-1、K_19=R(δ)T(-g)。把任意常量 K_i 写成

    K_i = R(β_i) Tx(ℓ_i) R(γ_i).

普通因子有 ℓ_i=1、β_i=γ_i=0。ground 因子有 ℓ_19=√65、β_19=atan2((R(δ)(-g))_y,(R(δ)(-g))_x)、γ_19=δ-β_19。因此跨 ground 的三元组绝非三条等长单位杆；最后两类 source 标签尤其不能套用等长捷径。

令被动循环序列为 a,b,c，活动余项 C=A_(c+1)…A_(a-1)。因子可逆保证原闭环 F=I 等价于循环闭环 A_a A_b A_c C=I，因此目标 T=C^-1。进一步有

    A_a A_b A_c = R(θ1)Tx(ℓ_a)R(θ2)Tx(ℓ_b)R(θ3)Tx(ℓ_c)R(γ_c)
    θ1 = s_a q_a + β_a
    θ2 = s_b q_b + γ_a + β_b
    θ3 = s_c q_c + γ_b + β_c.

设 T 的平移为 p、转角为 ψ，标准 3R 目标转角为 φ=ψ-γ_c。腕点 w=p-ℓ_c(cosφ,sinφ)。两分支由

    c2 = (||w||²-ℓ_a²-ℓ_b²)/(2ℓ_aℓ_b)
    θ2 = atan2(σ√(1-c2²),c2), σ∈{+1,-1}
    θ1 = atan2(w_y,w_x)-atan2(ℓ_b sinθ2,ℓ_a+ℓ_b cosθ2)
    θ3 = φ-θ1-θ2

直接给出，再按上述仿射关系逐项解回编码器 q。算法没有 NR、最小二乘、迭代求根或失败后的数值回退。其物理解不仅满足相同位置约束，还满足包含 δ 的完整物理姿态约束。

## 与作者 20 个被动标签的对应关系

作者原 project 的赋值语句给出的真实被动坐标如下，而不是对所有标签机械使用 p,p+1,p+2：

| 作者标签 p | 按循环正方向排列的被动坐标 | 作者解的方向 |
|---|---|---|
| 0…16 | p,p+1,p+2 | 正向 |
| 17 | 17,18,19 | 原源码逆向赋 q19,q18,q17 |
| 18 | 19,0,1 | 原源码含 ground 的右基座分类 |
| 19 | 18,19,0 | 原源码含 ground 的左基座分类 |

因此 label→cyclic_start 为 [0,…,17,19,18]。证据是原 apc_class.cpp 的四个 nc 分支；本实现仅依据其赋值坐标核对标签，没有复制其源码。

作者 IKp 使用 Φ 符号和 qIK_middle=π+Φ 的数学结构，其 branch0 对应 sin(qIK_middle)>0、branch1 对应负号。在物理 offset 与数学 π 分离后，正向结构 p0…16 与 p18 的 branch0 对应标准 θ2 正号；反向结构 p17、p19 对应负号。具体地，p17 的 θ2=-qIK_middle；p18 的 θ2=q0+γ19≡qIK_middle；p19 的 θ2=-q19+β19≡-qIK_middle，模运算均使用真 2π。

这里的最后两个等价关系指几何一致恢复式：若 α=atan2(4,7)，则 β19≡α+δ-π、γ19≡π-α；p18 恢复 q0≡π+qIK_middle+α，p19 恢复 q19≡qIK_middle+β19。旧源码则把近似 PI_ 混入了这些三角恒等式，故 p18/p19 的旧数值标签在距分支边界 O(|δ-π|) 的区域不能宣称与新解逐字节等价。新日志同时保存 source 结构标签与真实标准 θ2 的正负；真实分支判据以 θ2 为准。原始旧源码、失败与标签数值保留。

## 正则性、边界与 chart 的处理

在闭环处，循环 SE(2) 共轭的伴随行列式为 1，因此有序被动 Jacobian 的行列式为 s_a s_b s_c ℓ_aℓ_b sinθ2。这独立证明了这两个分支的真正会合条件 sinθ2=0。

1. |c2|>1：无实数解。若仅在显式 32ε_mach 量级诊断带内越界，标记 UNREACHABLE_ROUNDOFF_AMBIGUOUS；不把 c2 clip 到 [-1,1]，不改腕点，不计成功。
2. c2=±1 且腕点非退化：SINGULAR_BOUNDARY，保留数学候选及会合分支身份；不计为 PCS 正则成功。
3. ℓ_a=ℓ_b 且 w=0、c2=-1：DEGENERATE_INFINITE，θ1 任意、θ3=φ-θ1-π。禁止用 atan2(0,0) 任取一个角并声称独立分支成功。
4. 0<sin²θ2≤10^-6：数学上是正则近边界，但保留作者 IKp 原有的 sin²θ2>10^-6 资格门，标记 source_regular_eligible=false。门数值未放宽。
5. 所有实数编码器解只按真 2π 的整数倍列举落在 source chart 内的代表。由于 source chart 宽度 2δ 略大于真 2π，极小接缝区域可能有两种字面代表，必须全部保留，不能偷偷选择更近的代表或对活动坐标做周期整理。APC 自身没有最近邻选择策略。
6. 活动 17 个数值逐个原样复制；输入不闭合也不重置。所有候选的原生闭环位置残差、姿态残差与完整链残差分别保存，source unit 与 rad 不混合求范数。

## 接口与可审查限制

纯标准库模块 planar_geometry.py 提供 project_apc(q,label,branch)、passive_indices(label)、canonical_branch_sign(label,branch)、closure_residual(q)、closure_jacobian(q)、full_chain(q)、model_metadata()。输入不是有限 20 维状态时明确抛出异常。project_apc 返回 JSON 可序列化字典；candidates 是所有 chart lifts，可能为空；regular_candidate_count 只统计 source 正则门与 chart 均成立者。函数并未把残差阈值写成成功判据，资格 runner 必须按冻结协议独立评分。

closure_jacobian 是本实现的解析导数，不得同时充当自己的独立真值 oracle。独立证据应使用另外写出的累计角点位求和、完整矩阵连乘、独立差分或手工可解的正反解 fixture。所有真实运行必须保存输入、原输出、残差、资格判据、源码哈希及预算消耗。本文下列建议不代表实验已经执行，也不预先改变统一协议。
