# D083：有预算界PCS困难条件诊断

## 研究问题

我在既有20R闭链模型上检验PCS在三个预先冻结的端点条件中是否表现出相对于兼容固定划分、NR和RSS的规划优势。端点来自既有PCS成功路径，不能作为无偏困难场景样本。本研究仅检验这组确定性诊断条件；没有寻找最有利的seed或移动障碍。

## 证据来源与公平对照

C1、C2、C3依次连接旧E1/PCS密集资格路径seed7、23、41的序号152/305、204/409、310/621中间构型（序号从0开始）。每条可行见证由第一路径前缀倒序至精确公共START，再接第二前缀，全部离散构型独立复核。兼容固定划分由实际可用p0/p16的端点分支先验检查决定，不将结构性不兼容当作算法失败。

生产源码、输入端点及配置在9f2028cf冻结。使用既有E1障碍、链长、2mm链半径、170组非相邻碰撞对、±π关节范围和1e−8米/rad闭链门限。所有规划器调用沿用D081预算，实际PCG64 seed配对，算法消耗随机数的数量可能不同。

## 困难程度

独立固定深度递归投影候选用于判断某条候选路线是否存在闭链、限位合格的碰撞构型。IK不可达或NR不收敛单独记录，不能当作环境障碍证据。具体候选被挡仍不等于证明拓扑窄通道；未发现障碍时必须记NOT_ESTABLISHED_HARD。

## 与原文的关系及结论边界

原文Table I在环境II的Bi-RRT平均耗时RSS7.27s、PCS0.22s、NR0.13s，环境III为23.10s、1.06s、0.92s，各格500次、上限1000s。这些是原论文的空间环境统计，不能与本次重建20R、1秒上限、三条件×三seed诊断直接计算性能倍率。原文有关更复杂障碍PCS优势的讨论主要关联IV–VI，本次不恢复这些范围。

离散资格与两层独立中点加密没有证明连续碰撞安全或物理执行。归档端点选择偏向旧PCS可达区域，小分母和墙钟上限可能影响成功/超时边界，负/未定结论不能推出PCS在所有复杂空间场景无效。
